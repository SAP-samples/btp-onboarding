# Sales Operations Assistant — DC Mission

This directory contains the structured DC Mission documentation for the **Sales Operations Assistant** within SAP Autonomous Finance.

## Overview

The Sales Operations Assistant is a Joule Assistant within SAP Autonomous Finance. It automates the identification and resolution of sales order fulfilment issues — including delivery blocks, billing blocks, credit blocks, and supply problems — and supports the creation of sales orders from unstructured purchase order documents. All corrective actions require human approval before execution.

> This guide targets SAP administrators and IT teams activating the Sales Operations Assistant for their organisation.
