## Test Scripts — Sales Operations Assistant (Private Cloud)

### Billing Block Resolution Agent

> Source: `Billing_Block_Resolution_Agent_-_End_User_Testing_Guide.pdf`
> Roles: `SAP_BR_INTERNAL_SALES_REP`, `SAP_BR_BILLING_CLERK`

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Analyze billing block | Open Joule; query billing block details for a known sales order | Agent returns billing block details; optionally offers to change payment terms |
| 2 | Remove block at header level | Request removal of billing block at header level; confirm action (HITL) | Block removed at header level; confirmed in S/4HANA |
| 3 | Remove block at item level | Request removal of billing block at item level | Block removed at item level |
| 4 | Create billing document | After block removal, request billing document creation for order-related or delivery-related items | Billing document created successfully |
| 5 | Negative test — apply block | Ask agent to apply a billing block | Agent refuses (it only removes billing blocks, not applies them) |

### Credit Block Resolution Agent

> Source: `Credit_Block_Resolution_Agent_-_End_User_Testing_Guide.pdf`
> Roles: `SAP_BR_BILLING_CLERK`, `SAP_BR_INTERNAL_SALES_REP`; Scope item: BD9

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Review SO credit block | Query credit block for a known sales order (payment card issue) | Agent identifies credit block reason and presents action plan |
| 2 | Approve and execute plan | Approve agent actions to reauthorize payment card (HITL) | Credit block resolved; payment card reauthorized in S/4HANA |
| 3 | Modify execution plan | Request agent to switch recommended action (e.g., credit recheck instead of card reauth); execute modified plan | Modified plan executed successfully |
| 4 | Fallback options | When agent cannot resolve automatically, test fallback buttons | Agent presents: **View Billing Due List**, **Open Credit Decision App**, **Draft and Contact Credit Analyst** |

### Delivery Issue Resolution Agent

> Source: `Delivery_Issue_Resolution_Agent_-_End_User_Testing_Guide.pdf`
> Roles: `SAP_BR_INTERNAL_SALES_REP`, `SAP_BR_SHIPPING_SPECIALIST`

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Identify delivery issues | Query delivery issues for a known sales order | Agent returns action plan with recommendations and messages per line item |
| 2 | Query item details | Ask for specific item fields (plant, shipping point, ATP fields) | Agent returns requested field details |
| 3 | Execute — quantities confirmed | Request delivery creation when quantities are confirmed; confirm (HITL) | Delivery document created; document number and Fiori navigation links returned |
| 4 | Execute — quantities not confirmed | Request delivery creation when quantities are not confirmed | Agent reports no deliveries possible; suggests manual steps (change RDD, alternate material, reject line item) |
| 5 | Modify action plan | Request split into separate deliveries per item; execute modified plan | Modified plan executed per request |
| 6 | Complete Delivery flag | Test with customer that has Complete Delivery flag set | Agent highlights that not all items are confirmed; delivery creation fails; agent suggests waiting or removing flag |

### Supply Issue Resolution Agent

> Source: `Supply_Issue_Resolution_Agent_-_End_User_Testing_Guide.pdf`
> Role: `SAP_BR_INTERNAL_SALES_REP`

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | All issue categories | Prompt covering supply, purchasing, and manufacturing issues for a sales order | Agent returns consolidated view with recommendations per category |
| 2 | Supply issues | Request supply issues only for a sales order | Agent returns item IDs, product, due days, PR confirmation status; recommends contacting MM to convert PR to PO |
| 3 | Purchasing issues | Request purchasing issue detail | Agent returns PO numbers, delivery schedule, supplier confirmation status, purchasing group contact details, and recommended actions |
| 4 | Manufacturing issues | Request manufacturing issue detail | Agent returns manufacturing order details (scheduled/confirmed dates, delay reason); suggests contacting production supervisor |
