## SAP Autonomous Finance — Introduction

**SAP Autonomous Finance** is a suite of AI-powered assistants built on Joule that automate finance and sales operations processes. The assistants are embedded in the user's workflow through SAP Build Work Zone and operate on top of SAP S/4HANA Cloud — both SAP S/4HANA Cloud Public Edition and SAP S/4HANA Cloud Private Edition.

Each assistant targets a specific business process, identifies issues, and proposes corrective actions. All execution requires human approval.

---

### What This Mission Covers

This DC Mission covers the end-to-end activation of SAP Autonomous Finance assistants for both deployment models:

- **SAP S/4HANA Cloud Public Edition** — covered in phase 3
- **SAP S/4HANA Cloud Private Edition** — covered in phase 4

The mission is structured as follows:

| Phase | Scope |
|-------|-------|
| 1 – Discover | Overview of SAP Autonomous Finance and available assistants |
| 2 – Prepare | Prerequisites before provisioning — split by SAP S/4HANA Cloud Public Edition and SAP S/4HANA Cloud Private Edition |
| 3 – Provisioning (Public Cloud) | Activation steps per assistant for SAP S/4HANA Cloud Public Edition |
| 4 – Provisioning (PCE) | Activation steps per assistant for SAP S/4HANA Cloud Private Edition |

> **Note:** Before provisioning any assistant, there are pre-steps required at the system level — such as provisioning SAP Managed Joule and setting up the Joule integration with your SAP system. These are covered in a separate guide. The link will be added here once available.

### Key Principles

- **AI-assisted, human-approved** — Assistants recommend and propose actions; humans approve before execution
- **Embedded in the workflow** — Available directly through Joule in SAP Build Work Zone
- **Context-aware** — Each assistant accesses the relevant SAP S/4HANA data to analyse the situation and recommend actions
