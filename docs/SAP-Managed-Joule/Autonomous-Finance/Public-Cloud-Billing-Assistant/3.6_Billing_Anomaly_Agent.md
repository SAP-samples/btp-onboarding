## Billing Anomaly Agent

**Identifier:** J1550 | [Discovery Center](https://discovery-center.cloud.sap/protected/index.html#/ai-agent/67f059aa-a70a-4896-84fc-a8ee4db5eb26/)

### Objective

Detects unusual taxes and abnormal charges in billing documents and flags anomalies for review. The agent helps billing specialists identify discrepancies before invoices are sent to customers, preventing revenue leakage and compliance issues.

### What It Can Do

- Scan billing documents for unusual tax amounts and abnormal charges
- Flag anomalies for review before billing documents are posted
- Provide explanations of detected anomalies to support informed decisions
- Help maintain billing accuracy and compliance

### Prerequisites

| Requirement | Details |
|-------------|---------|
| System | SAP S/4HANA Cloud Public Edition |
| Scope item | **BD9** (Sell from Stock) |
| IAM apps | `F9467_TRAN`, `F8827_TRAN`, `F0797A_TRAN`, `F9202_TRAN` — assign to business role via **Maintain Business Roles** |
| Feature flag | `BillingAssistant` (`SDBIL_BILLING_ASSISTANT`) — activate via incident on **SD-BIL-AIA** |

> The agent uses the SAP-RPT-1 model. Findings are displayed in the **Manage Billing Documents - Version 2** app.

### Works With

- SAP S/4HANA Cloud Public Edition
