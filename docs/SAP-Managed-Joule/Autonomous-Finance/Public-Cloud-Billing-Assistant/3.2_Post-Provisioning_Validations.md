## Post-Provisioning Validations (Public Cloud)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following group exists:
   - `joule_end_user`

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent-Specific Validations

After provisioning, verify the following for the Billing Assistant:

#### Required IAM Apps by Agent

Assign the following IAM apps to the relevant business roles in the **Maintain Business Roles** app. For more information, see [Work with IAM Apps](https://help.sap.com/docs/SAP_S4HANA_CLOUD/55a7cb346519450cb9e6d21c1ecd6ec1/65e28884ea434cf3ba68c1f0e62e8a53.html).

| IAM App | SAP Fiori App Name | Agent |
|---------|-------------------|-------|
| `F9202_TRAN` | Joule Plugin | All agents |
| `F9466_TRAN` | Schedule Billing Creation Agent | Billing Creation Agent |
| `F8827_TRAN` | Manage Billing Documents with AI | Billing Creation Agent, Billing Anomaly Agent, Billing Posting Agent |
| `F0798_TRAN` | Create Billing Documents | Billing Creation Agent |
| `F9467_TRAN` | Schedule Billing Anomaly Agent | Billing Anomaly Agent, Billing Adjustment Agent |
| `F0797A_TRAN` | Manage Billing Documents - Version 2 | Billing Anomaly Agent, Billing Adjustment Agent, Billing Posting Agent |
| `F3893_TRAN` | Manage Sales Orders - Version 2 | Billing Adjustment Agent |
| `F9468_TRAN` | Schedule Billing Posting Agent | Billing Posting Agent |

> **Note:** You can only access the Billing Assistant IAM apps and their app descriptions once SAP has activated the `BillingAssistant` feature flag (`SDBIL_BILLING_ASSISTANT`).

#### Feature Flag Activation

The Billing Assistant requires the `BillingAssistant` feature flag (`SDBIL_BILLING_ASSISTANT`) to be active in your system. To activate it, create a support incident on component **SD-BIL-AIA**.

> Note: You can only access the Billing Assistant IAM apps and their app descriptions once SAP has activated the `BillingAssistant` feature flag.

#### Scope Item

Scope item **BD9** (Sell from Stock) must be active in your SAP S/4HANA Cloud Public Edition system.

#### Billing Policy Document

The Billing Creation Agent and Billing Posting Agent require a billing policy document per sales organization. Upload the document to Joule before running these agents.

SAP provides a template — download it from the SAP Help Portal:
[Billing Assistant — SAP Help Portal](https://help.sap.com/docs/AUTONOMOUS_FINANCE_DOMAIN/c4c363ea6a7148dd896991679f786cf6?locale=en-US&state=PRODUCTION&version=1.0)

> **Tip:** We recommend using SAP's example billing policy document as a template. Adapt it to reflect your business requirements, then upload it to Joule per sales organization.

#### Functional Checks

- Log in to Joule and type `@Billing Assistant` to confirm the orchestration agent responds.
- Test the Billing Creation Agent by requesting prioritization of the billing due list for a sales organization.
- Test the Billing Anomaly Agent by requesting anomaly detection for a billing document or sales organization.
- Test the Billing Posting Agent by requesting resolution of posting errors for a sales organization.
- Verify findings appear in the **Manage Billing Documents - Version 2** app under the **Posting Issue Resolution** view.

#### Example Prompts to Test the Assistant
