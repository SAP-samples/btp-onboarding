### Prerequisites

#### System Access

| System | Details |
|--------|---------|
| SAP S/4HANA Cloud Public Edition | Accessible via the SAP Fiori launchpad, with the Joule assistant panel enabled. Run each multi-turn test in a fresh Joule conversation to keep session memory isolated. |

#### Business Roles

| Business Role | ID |
|---------------|----|
| Billing Clerk | `SAP_BR_BILLING_CLERK` |
| Accounts Receivable Accountant (adjustment/posting flows) | `SAP_BR_AR_ACCOUNTANT` |

#### Additional Configuration

| Configuration | Detail |
|---------------|--------|
| Feature flag | `SDBIL_BILLING_ASSISTANT` activated |
| Policy document | Billing Policy uploaded for Sales Org 1010 via Joule before running most test cases |

#### Business Conditions

| Business Condition | Detail |
|-------------------|--------|
| Scope item BD9 | Sell from Stock (BD9) activated |
| Test billing documents | Prepare one document per required status/scenario (see test data tables below) |
| Historical billing data | Sufficient historical billing documents must exist for the customer/material/country combinations in the test data — required for the SAP-RPT-1 model to produce reliable predictions |
| Agent jobs completed | At least one completed agent run for each sales org used in a test case (1010, 2020, 1710) before those test cases are executed |
| Scheduled job | At least one job created in the **Schedule Billing Posting Agent** app and completed before checking results |

> **Important:** Ensure that the test data set is exclusive for each test case. If multiple scheduled agent jobs run at the same time, there can be conflicts and errors in the results. Do not schedule agent jobs back-to-back within an interval of a few seconds on the same data set.
