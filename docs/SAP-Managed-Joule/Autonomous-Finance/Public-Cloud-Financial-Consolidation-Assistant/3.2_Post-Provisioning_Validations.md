## Post-Provisioning Validations (Public Cloud)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following group exists:
   - `joule_end_user`

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent-Specific Validations

After provisioning, verify the following for the Financial Consolidation Assistant:

#### Required Roles

Confirm the following business roles are assigned to the user before testing:

| Role | Required For |
|------|-------------|
| Local accountant / consolidation user role | All Financial Consolidation agents (common prerequisite) |

#### Functional Checks

- Log in to Joule and type `@Financial Consolidation Assistant` to confirm the orchestration agent responds.
- Test the Financial Consolidation Data Submission Agent by requesting submission status for a consolidation unit.
- Confirm that the user has the required consolidation authorizations before testing agents.
