## Financial Consolidation Orchestration Agent

**Identifier:** J2223 | [Discovery Center](https://discovery-center.cloud.sap/protected/index.html#/ai-agent/a0b68a78-bfc6-47a9-8501-d8f36449341f/)

### Objective

Coordinates the specialised agents within the Financial Consolidation Assistant. The orchestration agent receives user requests through Joule, determines which sub-agent is best suited to handle each task, and dispatches accordingly — covering consolidation data submission and error resolution.

### What It Can Do

- Interpret natural language requests and route them to the appropriate Financial Consolidation sub-agent
- Coordinate consolidation data submission tasks
- Provide a single entry point for all Financial Consolidation Assistant interactions in Joule

### Sub-agents Coordinated

| Sub-agent | Responsibility |
|-----------|---------------|
| Financial Consolidation Data Submission Agent | Automate data submissions and resolve submission errors |

### Works With

- SAP S/4HANA Cloud Public Edition

### Example Prompts

| Prompt |
|--------|
| "Help me with financial consolidation." |
| "What can the Financial Consolidation Assistant help me with?" |
| "Submit consolidation data for consolidation unit [unit]." |

> **Note:** The orchestration agent does not perform tasks directly. All consolidation actions are executed by the sub-agents it coordinates.
