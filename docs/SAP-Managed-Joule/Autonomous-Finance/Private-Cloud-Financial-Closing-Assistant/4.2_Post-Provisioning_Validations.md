## Post-Provisioning Validations (PCE)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following group exists:
   - `joule_end_user`

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent Access Assignment

After SAP-managed provisioning jobs complete, authorization groups for each agent are available in SAP Cloud Identity Services. You must assign users to these groups to grant them access to the agents.

**Prerequisites:**
- SAP-managed provisioning jobs have completed successfully and agent authorization groups are available in SAP Cloud Identity Services
- The users you want to assign already exist in SAP Cloud Identity Services
- You are assigned an administrator role with the **Manage Users** or **Manage Groups** authorizations in the SAP Cloud Identity Services administration console

> Each agent has its own authorization group. Users must be members of an agent's group to see and interact with that agent. Assigning a user to an assistant does not automatically grant access to the agents it invokes — you must assign the user to each one separately.

**Steps:**

1. Sign in to the administration console for SAP Cloud Identity Services.
2. Under **Users & Authorizations**, choose the **Groups** tile.
3. Search for the agent authorization group required.
4. Choose **+ Add**.
5. Add users to the group.
6. Save your changes.

### Agent-Specific Validations

After provisioning, verify the following for the Financial Closing Assistant:

#### Required Roles and Business Catalog

Confirm the following business roles and catalogs are assigned to the user before testing:

| Role / Catalog | Required For |
|----------------|-------------|
| Business catalog `SAP_FIN_BC_GL_JE_PROC_PC` (General Ledger - Journal Entry Processing) with restriction type `BUKRS` | Accounting Accruals Agent, Journal Entry Agent |
| Asset Accountant business role | Asset Accounting Anomaly Detection Agent (PCE only) |
| Authorization objects: `F_BKPF_BUK`, `F_SKA1_BUK`, `F_FAGL_LDR`, `F_FDCA_CHK`, `F_CC_HIER` | Financial Consistency Analysis Agent (PCE only) |

#### Required IAM Apps by Agent

| Agent | IAM App |
|-------|---------|
| Journal Entry Agent | `F9263_TRAN` (Manage Journal Entry Proposals) |
| Accounting Accruals Agent | `F8860_TRAN` (Manage Accrual Proposals) |
| Analytical Business Insights Agent | `F8587_TRAN` (Financial Statements Review Booklet) |
| Receivables and Payables Clearing Agent | `F9300_TRAN` (Manage Supplier Clearing Proposals), `F9287_TRAN` (Manage Customer Clearing Proposals) |

#### Scope Items

Confirm the following scope items are activated:

| Scope Item | Description |
|------------|-------------|
| J58 | Accounting and Financial Close |
| J59 | Accounts Receivable |
| J60 | Accounts Payable |

#### Feature Flag

| Feature Flag | Required For |
|--------------|-------------|
| `FINS_ACCR_PROPOSALS` | Accounting Accruals Agent |

#### Accruals Policy Handbook

The Accounting Accruals Agent requires an Accruals Policy Handbook containing the company's accounting policies, expense categories, and accrual calculation rules. Upload this via Joule when prompted.

#### Journal Entry Policy

You can optionally upload a policy file for a company code to define permitted posting combinations used by the Journal Entry Agent during proposal processing.

#### Functional Checks

- Log in to Joule and type `@Financial Closing Assistant` to confirm the orchestration agent responds.
- Test the Accounting Accruals Agent by requesting an accrual proposal — Joule should prompt you to upload a policy handbook.
- Test the Journal Entry Agent by uploading a spreadsheet file via Joule.
- Test the Receivables and Payables Clearing Agent by requesting clearing proposals for open items in a company code.
- For the Asset Accounting Anomaly Detection Agent (PCE only): request anomaly detection for a company code and confirm results are returned.
- For the Financial Consistency Analysis Agent (PCE only): request a consistency check for a company code and fiscal year and confirm the agent responds.

#### Example Prompts to Test the Assistant

| Prompt |
|--------|
| `@Financial Closing Assistant: Create a journal entry proposal.` |
| `@Financial Closing Assistant: Create accrual entries for the current period.` |
| `@Financial Closing Assistant: What are the next steps in my financial close after posting the journal entries?` |
| `@Financial Closing Assistant: Show me the assets which have a depreciation key mismatch in company code 1000.` |
| `@Financial Closing Assistant: Check the consistency of journal entries posted in period 3 of fiscal year 2026 company code 1010.` |
