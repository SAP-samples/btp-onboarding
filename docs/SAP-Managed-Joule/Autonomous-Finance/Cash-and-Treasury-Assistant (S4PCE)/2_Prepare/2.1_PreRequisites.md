## Pre-Requisites

The following components must be in place before the Cash and Treasury Assistant can be activated.

- **SAP S/4HANA Cloud Private Edition** — Minimum release: SAP S/4HANA 2023 FPS01.

- **SAP Managed Joule (SMJ) — fully provisioned** — SMJ must be fully provisioned and active. For provisioning instructions, refer to the [SAP Managed Joule Provisioning guide](https://help.sap.com/docs/joule/joule-work-621104a90a01407fbb2d1613db39a54d/sap-managed-provisioning).

- **Joule integration with SAP S/4HANA Cloud Private Edition — configured** — For setup instructions, refer to the [Joule Integration guide](https://help.sap.com/docs/joule/integrating-joule-with-sap/integration-with-sap-s-4hana-cloud-private-edition).

- **SAP Cloud Identity Services (CIS) — active tenant** — Users must be assigned to the `joule_end_user` group in CIS (see section 3.2).

- **S-user with SAP for Me authorisations** — The activating user must have **Display Cloud Data** and **Edit Cloud Data** permissions in SAP for Me.

### Agent-Specific Requirements

#### Cash Positioning Agent

| Requirement | Details |
|-------------|---------|
| Business Roles | `SAP_BR_CASH_MANAGER` and `SAP_BR_CASH_SPECIALIST` |
| Minimum Release | SAP S/4HANA 2023 FPS01 |
| APIs Required | `UI_SHORTTERMCASHPOS_AI_C1_V4`, `FCLM_CASH_BANKTRANSFER_SRV_C1_V2`, `FCLM_CASH_BANKTRANSFERTEM_SRV_C1_V2`, `UI_CashPosition_AI_C1_V4` |
| SAP Notes | 3576432 (OData API changes), 3616238 (Bank Transfer backend), 3724030 (Bank Transfer backend) |
| Additional | Treasury Policy must be defined; Cash Position Profile must be maintained; Bank Transfer Templates must be available |

#### Bank Relationship Agent

| Requirement | Details |
|-------------|---------|
| Configuration | In Customizing activity **Define Basic Settings**, set **Full Scope** for the **Cash Scope** setting |
| IAM App | `F8926_TRAN` (Bank Relationship Management via API) assigned to user |
| Bank Hierarchy | Set up in Manage Bank Accounts – Bank Hierarchy View app (F1366) |
| FI Components | Cash and Liquidity Management (FIN-FSCM-CLM), Treasury and Risk Management (FIN-FSCM-TRM), Bank Statements (FI-BL-PT-BA) |
