## Complete the Mission

Congratulations on completing the Cash and Treasury Assistant setup! Use the checklist below to confirm that all required steps have been completed and validated before marking the mission as done.

### Mission Completion Checklist

**Pre-Requisites**

- [ ] SAP S/4HANA Cloud Private Edition release 2023 FPS01 or later available
- [ ] SAP Managed Joule fully provisioned and active
- [ ] Joule integration with SAP S/4HANA Cloud Private Edition configured
- [ ] SAP Cloud Identity Services active tenant available
- [ ] S-user with Display Cloud Data and Edit Cloud Data permissions in SAP for Me

**Cash Positioning Agent**
- [ ] Business roles `SAP_BR_CASH_MANAGER` and `SAP_BR_CASH_SPECIALIST` assigned
- [ ] Required APIs active (UI_SHORTTERMCASHPOS_AI_C1_V4 and related)
- [ ] SAP Notes 3576432, 3616238, 3724030 implemented
- [ ] Treasury Policy defined
- [ ] Cash Position Profile maintained
- [ ] Bank Transfer Templates available

**Bank Relationship Agent**
- [ ] Full Scope set for Cash Scope in Define Basic Settings (Customizing activity)
- [ ] IAM app F8926_TRAN assigned to user
- [ ] Bank hierarchy set up in app F1366
- [ ] FIN-FSCM-CLM, FIN-FSCM-TRM, FI-BL-PT-BA components active

**Set Up Phase**

- [ ] Cash and Treasury Assistant activated in SAP for Me under Autonomous Finance
- [ ] Activation confirmed — assistant visible in Joule interface
- [ ] Users added to the `joule_end_user` group in SAP Cloud Identity Services
- [ ] IPS synchronisation run (if applicable)
- [ ] Test user login to Joule confirmed — Cash and Treasury Assistant available

**Agents Validated**

- [ ] Cash and Treasury Orchestration Agent tested with at least one example prompt
- [ ] Cash Positioning Agent tested (e.g., "Perform daily cash positioning")
- [ ] Bank Relationship Agent tested (e.g., "What is our relationship with Bank ABC?")

### Mark the Mission Complete

Once all required steps are confirmed, mark your DC Mission as complete on the project board.
