# Recurring Receivables Assistant - DC Mission

This directory contains the files for the **Recurring Receivables Assistant DC Mission** — a structured guide for activating, configuring, and validating the Recurring Receivables Assistant within SAP Autonomous Finance.

## Overview

The Recurring Receivables Assistant automates order-to-cash processes for recurring billing, subscription-based revenue, and contract accounting. It coordinates specialised agents to manage collection insights, invoice corrections, and subscription contract lifecycle changes. All corrective actions require human approval before execution.

> This guide targets SAP administrators and finance teams activating the Recurring Receivables Assistant for their organisation.
