## Pre-Requisites

The following components must be in place before the Recurring Receivables Assistant can be activated.

- **SAP S/4HANA Cloud, Private Edition** — Release 2025 FPS01 or later required.

- **SAP Managed Joule (SMJ) — fully provisioned** — SMJ must be fully provisioned and active. For provisioning instructions, refer to the [SAP Managed Joule Provisioning guide](https://help.sap.com/docs/joule/joule-work-621104a90a01407fbb2d1613db39a54d/sap-managed-provisioning).

- **Joule integration with SAP S/4HANA Cloud Private Edition — configured** — For setup instructions, refer to the [Joule Integration guide](https://help.sap.com/docs/joule/integrating-joule-with-sap/integration-with-sap-s-4hana-cloud-private-edition).

- **FI-CA Module** — Contract Accounting (FI-CA) module must be active and configured in the system.

- **SAP Cloud Identity Services (CIS) — active tenant** — Users must be assigned to the `joule_end_user` group in CIS (see section 3.2).

- **S-user with SAP for Me authorisations** — The activating user must have **Display Cloud Data** and **Edit Cloud Data** permissions in SAP for Me.
