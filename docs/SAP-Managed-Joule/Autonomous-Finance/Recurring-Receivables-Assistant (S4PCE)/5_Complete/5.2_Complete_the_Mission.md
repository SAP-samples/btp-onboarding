## Complete the Mission

Congratulations on completing the Recurring Receivables Assistant setup! Use the checklist below to confirm that all required steps have been completed and validated before marking the mission as done.

### Mission Completion Checklist

**Pre-Requisites**

- [ ] SAP S/4HANA Cloud, Private Edition release 2025 FPS01 or later available
- [ ] SAP Managed Joule fully provisioned and active
- [ ] Joule integration with SAP S/4HANA Cloud Private Edition configured
- [ ] Contract Accounting (FI-CA) module active and configured
- [ ] SET/GET parameter 8RA defined in user profile (for Collection Insights Agent)
- [ ] Business role `SAP_BR_INVOICING_SPEC_CINV` assigned (for Convergent Invoice Execution Agent)
- [ ] SAP Note 3803943 implemented (for Convergent Invoice Execution Agent)
- [ ] Business role `SAP_BR_INTRNAL_SALESREP_SOM` assigned (for Subscription Lifecycle Agent)
- [ ] Required MCPs active (for Subscription Lifecycle Agent)
- [ ] SAP Note 3748784 implemented (for Subscription Lifecycle Agent)
- [ ] S-user with Display Cloud Data and Edit Cloud Data permissions in SAP for Me

**Set Up Phase**

- [ ] Recurring Receivables Assistant activated in SAP for Me under Autonomous Finance
- [ ] Activation confirmed — assistant visible in Joule interface
- [ ] Users added to the `joule_end_user` group in SAP Cloud Identity Services
- [ ] IPS synchronisation run (if applicable)
- [ ] Test user login to Joule confirmed — Recurring Receivables Assistant available

**Agents Validated**

- [ ] Collection Insights Agent tested with at least one example prompt
- [ ] Convergent Invoice Execution Agent tested with at least one example prompt
- [ ] Subscription Lifecycle Agent tested with at least one example prompt

### Mark the Mission Complete

Once all required steps are confirmed, mark your DC Mission as complete on the project board.
