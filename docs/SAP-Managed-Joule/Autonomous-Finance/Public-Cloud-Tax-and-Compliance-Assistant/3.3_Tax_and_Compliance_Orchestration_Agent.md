## Tax and Compliance Orchestration Agent

**Identifier:** J2265 | [Discovery Center](https://discovery-center.cloud.sap/protected/index.html#/ai-agent/55d253ce-d56a-4962-8711-dbc13c5f4e4b/)

### Objective

Coordinates the specialised agents of the Tax and Compliance Assistant. The orchestration agent receives user requests through Joule, determines which sub-agent is best suited to handle each task, and dispatches accordingly — covering regulatory change discovery, document mapping explanations, and statutory report extension management.

### What It Can Do

- Interpret natural language requests and route them to the appropriate Tax and Compliance sub-agent
- Coordinate multi-step compliance tasks across regulatory discovery and reporting
- Provide a single entry point for all Tax and Compliance Assistant interactions in Joule

### Sub-agents Coordinated

| Sub-agent | Responsibility |
|-----------|---------------|
| Legal Change Agent | Regulatory compliance discovery |
| Regulatory Document Mapping Explanation Agent | Field-level mapping explanations for e-invoicing and statutory reporting |
| Statutory Report Extension Update Agent | Merge customer extensions with new SAP statutory report versions |

### Works With

- SAP S/4HANA Cloud Public Edition
- SAP Document and Reporting Compliance

### Example Prompts

| Prompt |
|--------|
| "Help me with tax and compliance." |
| "What regulatory changes affect my country?" |
| "What can the Tax and Compliance Assistant help me with?" |

> **Note:** The orchestration agent does not perform tasks directly. All compliance actions are executed by the sub-agents it coordinates.
