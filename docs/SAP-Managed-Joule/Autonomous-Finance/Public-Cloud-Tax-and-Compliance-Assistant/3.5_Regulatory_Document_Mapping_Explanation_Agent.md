## Regulatory Document Mapping Explanation Agent

**Identifier:** J1731 | [Discovery Center](https://discovery-center.cloud.sap/protected/index.html#/ai-agent/eae6b995-df8e-49d0-9b05-58ffc839e337/)

### Objective

Explains field-level mappings between source data, SAP documents, and e-invoicing or statutory reporting formats. The agent helps tax specialists and compliance teams understand how data flows from SAP source documents through to regulatory output, reducing reliance on technical documentation for mapping queries.

### What It Can Do

- Explain field-level mappings from SAP source data to e-invoicing and statutory reporting formats
- Identify which SAP fields contribute to a specific statutory report field
- Support troubleshooting of mapping issues in regulatory documents
- Reduce manual investigation time for compliance mapping queries

### Works With

- SAP S/4HANA Cloud Public Edition
- SAP Document and Reporting Compliance

### Example Prompts

| Prompt |
|--------|
| "Explain the mapping for field [field name] in the [report name] for [country]." |
| "Which SAP field maps to [statutory field] in the e-invoice format for [country]?" |
| "Show me the source of data for [report section] in [statutory report name]." |
