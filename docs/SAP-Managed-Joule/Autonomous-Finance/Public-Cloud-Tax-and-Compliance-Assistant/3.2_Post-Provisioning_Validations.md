## Post-Provisioning Validations (Public Cloud)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following group exists:
   - `joule_end_user`

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent-Specific Validations

After provisioning, verify the following for the Tax and Compliance Assistant:

#### Required Roles

Confirm the following business roles are assigned to the user before testing:

| Role | Required For |
|------|-------------|
| Tax specialist / compliance user role | All Tax and Compliance agents (common prerequisite) |

#### Functional Checks

- Log in to Joule and type `@Tax and Compliance Assistant` to confirm the orchestration agent responds.
- Test the Legal Change Agent by requesting regulatory change discovery for a country or regulation.
- Test the Regulatory Document Mapping Explanation Agent by requesting a field-level mapping explanation for a statutory report.
- Test the Statutory Report Extension Update Agent by requesting an extension update for a statutory report version.
- Confirm that users have the required tax and compliance authorizations before testing agents.
