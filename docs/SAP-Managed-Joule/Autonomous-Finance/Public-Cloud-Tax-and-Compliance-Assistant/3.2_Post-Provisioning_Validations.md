## Post-Provisioning Validations (Public Cloud)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following group exists:
   - `joule_end_user`

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent Access Assignment

After SAP-managed provisioning jobs complete, authorization groups for each agent are available in SAP Cloud Identity Services. You must assign users to these groups to grant them access to the agents.

**Prerequisites:**
- SAP-managed provisioning jobs have completed successfully and agent authorization groups are available in SAP Cloud Identity Services
- The users you want to assign already exist in SAP Cloud Identity Services
- You are assigned an administrator role with the **Manage Users** or **Manage Groups** authorizations in the SAP Cloud Identity Services administration console

> Each agent has its own authorization group. Users must be members of an agent's group to see and interact with that agent. Assigning a user to an assistant does not automatically grant access to the agents it invokes — you must assign the user to each one separately.

**Steps:**

1. Sign in to the administration console for SAP Cloud Identity Services.
2. Under **Users & Authorizations**, choose the **Groups** tile.
3. Search for the agent authorization group required.
4. Choose **+ Add**.
5. Add users to the group.
6. Save your changes.

### Agent-Specific Validations

After provisioning, verify the following for the Tax and Compliance Assistant:

#### Required Roles

Confirm the tax and compliance business role with the appropriate authorizations for statutory reporting and legal change discovery is assigned to the user before testing.

#### Agent-Specific Prerequisites

| Agent | Prerequisite |
|-------|-------------|
| Legal Change Agent | SAP Joule active — no additional system prerequisites required |
| Regulatory Document Mapping Explanation Agent | SAP Document and Reporting Compliance license required |
| Statutory Report Extension Update Agent | **Define Statutory Reports** configuration activity accessible; feature flag `GLO_FIN_SRF_MASS_SCHDL_SUMMARY` active |
| Statutory Report Analysis Agent | Scope item **5XU** (Statutory Report Analysis) activated; feature flag `GLO_FIN_SRF_MASS_SCHDL_SUMMARY` active; intelligent scenario `SRF_OUTLIER_DETERM` active; configuration parameters `SRF_ENABLE_REPORT_ANALYSIS` and `SRF_ANALYSIS_LOOKBACK_PERIODS` set; SAP Document and Reporting Compliance license required |

#### Feature Flags

| Feature Flag | Required For |
|--------------|-------------|
| `GLO_FIN_SRF_MASS_SCHDL_SUMMARY` | Statutory Report Extension Update Agent, Statutory Report Analysis Agent |

#### Functional Checks

- Log in to Joule and type `@Tax and Compliance Assistant` to confirm the orchestration agent responds.
- Test the Legal Change Agent by requesting regulatory change discovery for a country or regulation.
- Test the Regulatory Document Mapping Explanation Agent by requesting a field-level mapping explanation for a statutory report field.
- Test the Statutory Report Extension Update Agent by requesting an extension update for a statutory report version.
- If the Statutory Report Analysis Agent is activated, confirm scope item 5XU is active and test by requesting an analysis for a known statutory report.

#### Example Prompts to Test the Assistant

| Prompt |
|--------|
| `What regulatory changes apply to [country] in [year]?` |
| `Show me legal changes affecting VAT reporting for [country].` |
| `Explain the mapping for field [field name] in the [report name] for [country].` |
| `Update the extension for statutory report [report name] to the latest SAP version.` |
| `Show me conflicts between my extensions and the new version of [report name].` |
