## Test Scripts — Recurring Receivables Assistant (Private Cloud)

### Subscription Lifecycle Agent

> Source: `Subscription_Lifecycle_Agent_End_User_Testing_Guide.pdf`
> Roles: `SAP_BR_PROD_CONF_MODELR_SOM`, `SAP_BR_INTRNAL_SALESREP_SOM`, `S4C_SOM_REP`, `S4C_SOM_PROD`

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Agent launch | Open Joule and invoke the Subscription Lifecycle Agent | Agent responds and describes supported capabilities |
| 2 | Contract validation — active | Request details for a known active subscription contract | Agent returns PO number, dates, and status |
| 3 | Change PO on active contract | Request PO change on an active contract; confirm mandatory fields (PO number, start date, end date) (HITL) | PO updated on the contract |
| 4 | Change PO on already-changed contract | Attempt PO change on a contract already modified | Agent refuses or handles the edge case gracefully |
| 5 | Invalid contract ID | Request details for an invalid contract ID | Agent returns graceful error message |
| 6 | Inactive or planned contract | Request action on an inactive or planned contract | Agent refuses action and explains the contract status |
| 7 | Out-of-scope deflection | Ask an unrelated question (e.g., Excel help) | Agent deflects and stays in scope |
| 8 | Unauthorized action | Attempt an action the user has no permission for | Agent refuses and explains authorization requirement |

### Convergent Invoice Execution Agent

> Source: `Covergent_Invoicing_Execution_Agent___End_User_Testing_Guide.pdf`

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Agent launch | Open Joule and invoke the Convergent Invoice Execution Agent | Agent responds and describes supported capabilities |
| 2 | Resolve invoice to provider contracts | Query which provider contracts are linked to a known invoice | Agent returns linked provider contracts |
| 3 | Resolve provider contracts to invoices | Query which invoices are linked to a known provider contract | Agent returns linked invoices |
| 4 | Reprint invoice | Request reprint of an invoice to a printer | Invoice reprinted successfully |
| 5 | Reprint blocked by eInvoice | Attempt reprint on invoice that already has an existing eInvoice | Agent blocks action and explains the restriction |
| 6 | Create invoice adjustment request | Request creation of an invoice adjustment; confirm (HITL) | Adjustment request created in S/4HANA |
| 7 | Adjustment + invoice run | Create adjustment and trigger invoice run sequentially | Both actions completed successfully |
| 8 | Duplicate adjustment prevention | Attempt to create a duplicate adjustment request | Agent prevents duplicate and informs user |
| 9 | Out-of-scope deflection | Ask an unrelated question (e.g., SAP MM question) | Agent deflects appropriately |
| 10 | Unauthorized action | Attempt action without reprint permission | Agent refuses and explains authorization requirement |
