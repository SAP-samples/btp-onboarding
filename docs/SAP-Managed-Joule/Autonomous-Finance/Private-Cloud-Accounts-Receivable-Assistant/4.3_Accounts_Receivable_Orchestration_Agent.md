## Accounts Receivable Orchestration Agent

**Identifier:** J2224 | [Discovery Center](https://discovery-center.cloud.sap/protected/index.html#/ai-agent/e1344e4a-885e-4526-89a9-ad365f04a361/) | **Minimum Version:** SAP S/4HANA 2023 FPS02

### Objective

Coordinates the specialised agents within the Accounts Receivable Assistant. The orchestration agent receives user requests through Joule, determines which sub-agent is best suited to handle each task, and dispatches accordingly — covering receivable account analysis, collections preparation, email outreach, dunning insights, dispute creation, and dispute resolution.

### What It Can Do

- Interpret natural language requests and route them to the appropriate AR sub-agent
- Coordinate multi-step AR tasks across the full collections and dispute workflow
- Provide a single entry point for all Accounts Receivable Assistant interactions in Joule

### Sub-agents Coordinated

| Sub-agent | Responsibility |
|-----------|---------------|
| Receivable Account Analysis Agent | Provide comprehensive overview and insights into a customer account |
| Collection Account Preparation Agent | Streamline collection with real-time insights and recommendations |
| Collections Email Outreach Agent | Send personalised customer emails to collect outstanding receivables |
| Dunning Insights Agent | Accelerate collections with AI-driven dunning insights |
| Dispute Creation Agent | Create dispute cases from emails and Joule prompts |
| Dispute Resolution Agent | Automate validation of dispute cases and suggest actionable solutions |

### Works With

- SAP S/4HANA Cloud Private Edition

### Example Prompts

| Prompt |
|--------|
| "Help me with accounts receivable." |
| "Show me the receivable overview for customer [ID]." |
| "What can the Accounts Receivable Assistant help me with?" |

> **Note:** The orchestration agent does not perform tasks directly. All AR actions are executed by the sub-agents it coordinates.
