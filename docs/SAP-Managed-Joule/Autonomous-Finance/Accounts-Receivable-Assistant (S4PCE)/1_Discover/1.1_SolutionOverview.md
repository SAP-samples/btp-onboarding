## Accounts Receivable Assistant — Solution Overview

The **Accounts Receivable Assistant** is a Joule Assistant within SAP Autonomous Finance. It runs on SAP S/4HANA Cloud, Private Edition (RISE with SAP) and helps finance teams accelerate cash collection, resolve disputes efficiently, and manage credit risk proactively.

It improves operational efficiency and accelerates cash realisation by reducing manual activities, minimising delays, and ensuring consistent and compliant financial execution. The Accounts Receivable Orchestration Agent coordinates six specialised agents covering collection preparation, dispute management, clearing, and dunning. All corrective actions require human approval before execution.

### Prerequisites Summary

- SAP S/4HANA Cloud, Private Edition release 2025 FPS01 or later
- Joule via SAP-Managed Provisioning, version 2025 FPS01 or later
- Business role `SAP_BR_AR_ACCOUNTANT` assigned to all users requiring access
- SAP Dispute Management (FIN-FSCM-DM) and Collections Management (FIN-FSCM-COL) active

### Agents Used by This Assistant

| Agent | Scope |
|-------|-------|
| Accounts Receivable Orchestration Agent | Routes collection, dispute, clearing, and dunning requests to the appropriate agent |
| Receivable Account Analysis Agent | Consolidates overdue balances, payment behaviour, aging information, and dispute linkages |
| Collection Account Preparation Agent | Consolidates account data and provides real-time insights for collection specialists |
| Dispute Creation Agent | Creates dispute cases by processing unstructured data such as user prompts or email content |
| Dispute Resolution Agent | Validates dispute cases and suggests actionable resolution steps |
| Dunning Insights Agent | Retrieves dunning history and recommends follow-up actions based on payment patterns |

### Setup Process at a Glance

1. **Prepare** — Confirm that all prerequisites are in place before activation
2. **Set Up** — Provision the Accounts Receivable Assistant in SAP for Me and assign users in SAP Cloud Identity Services
