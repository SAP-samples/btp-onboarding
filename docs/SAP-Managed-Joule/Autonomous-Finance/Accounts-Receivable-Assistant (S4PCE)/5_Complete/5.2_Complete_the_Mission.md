## Complete the Mission

Congratulations on completing the Accounts Receivable Assistant setup! Use the checklist below to confirm that all required steps have been completed and validated before marking the mission as done.

### Mission Completion Checklist

**Pre-Requisites**

- [ ] SAP S/4HANA Cloud, Private Edition release 2025 FPS01 or later available
- [ ] SAP Managed Joule provisioned, version 2025 FPS01 or later
- [ ] Business role `SAP_BR_AR_ACCOUNTANT` assigned to all relevant users
- [ ] SAP Dispute Management (FIN-FSCM-DM) active
- [ ] Collections Management (FIN-FSCM-COL) active
- [ ] Scope item BFC activated (for Dispute Creation Agent)
- [ ] Required Fiori apps assigned to relevant users
- [ ] S-user with Display Cloud Data and Edit Cloud Data permissions in SAP for Me

**Set Up Phase**

- [ ] Accounts Receivable Assistant activated in SAP for Me under Autonomous Finance
- [ ] Activation confirmed — assistant visible in Joule interface
- [ ] Users added to the `joule_end_user` group in SAP Cloud Identity Services
- [ ] IPS synchronisation run (if applicable)
- [ ] Test user login to Joule confirmed — Accounts Receivable Assistant available

**Agents Validated**

- [ ] Accounts Receivable Orchestration Agent tested with at least one example prompt
- [ ] Receivable Account Analysis Agent tested with at least one example prompt
- [ ] Collection Account Preparation Agent tested with at least one example prompt
- [ ] Dispute Creation Agent tested with at least one example prompt
- [ ] Dispute Resolution Agent tested with at least one example prompt
- [ ] Dunning Insights Agent tested with at least one example prompt

### Mark the Mission Complete

Once all required steps are confirmed, mark your DC Mission as complete on the project board.
