## Test Scripts — Financial Closing Assistant (Public Cloud)

### Financial Closing Orchestration Agent

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Agent launch and introduction | Open Joule and invoke `@Financial Closing Assistant` | Agent responds and lists supported capabilities (journal entry upload, accruals, clearing, KPI analysis) |
| 2 | Route to Journal Entry Agent | Attach an `.xlsx` file and request journal entry proposal creation | Agent routes to Journal Entry sub-agent and returns column mapping tables with confidence percentages |
| 3 | Route to Accruals Agent | Request accrual proposals for a specific company code | Agent routes to Accrual Agent and prompts for policy handbook if not yet uploaded |
| 4 | Route to Clearing Agent | Request clearing of customer open items for a company code | Agent routes to Receivables and Payables Clearing Agent |

### Journal Entry Agent

> Source: `uat-script-journal-entry-agent-v1.docx`

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Agent launch | Open Joule; send prompt: *"Create journal entry proposal without checking for policy document"* | Agent confirms readiness without mentioning policy validation |
| 2 | File upload and mapping | Upload a prepared `.xlsx` journal entry file | Agent parses file and displays Header, Item, Debit, Credit column mapping tables with confidence percentages and document structure summary |
| 3 | Approve mapping | Click **Approve Mapping** | Agent proceeds to data transformation |
| 4 | No policy check | Verify no policy validation step or violation messages appear | Agent skips directly to proposal creation |
| 5 | Proposal creation | Agent creates journal entry proposals | Proposal ID (`JE_PROP_<timestamp>_<number>`), Company Code, Posting Date, Currency, and Total Amount returned |
| 6 | Verify in Fiori | Open app **Manage Journal Entry Proposals** (F9263) | Proposal has status "Open", correct header and line-item data, original Excel file attached |

### Analytical Business Insights (ABI) Agent

> Source: `F6132A_ReviewBooklet_-_ABI_Agent_2608_Sapphire.docx`

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Load report | Set filter bar (Ledger 0L, Company Code, Financial Statement Version, Fiscal Year, comparison year, currency type) and open Financial Statements Review Booklet | Report data loads |
| 2 | Calculate all KPIs | Prompt Joule: *"Calculate all KPIs"* | Agent generates full KPI list sorted by variance percentage |

| 6 | Summarize variance | Click **Summarize Variance** | Agent performs contribution analysis identifying the members driving the most variance |

### Receivables and Payables Clearing Agent — AR Side

> Source: `2026_E2E_APAR_AGENTS_AR.docx`
> Role: `SAP_BR_AR_ACCOUNTANT`; App: **Manage Customer Clearing Proposals** (F9287)

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Invoke agent | Open Joule and invoke `@Financial Closing Assistant`; request clearing of customer open items for a company code and customer | Agent acknowledges and starts processing |
| 2 | Receive notification | Wait for Bell and Email notification | Notification arrives when clearing proposals are created |
| 3 | Review proposals | Navigate to **Manage Customer Clearing Proposals** (F9287) via Bell notification | Proposal sets visible, grouped by currency, status "Pending Review" |
| 4 | Review reasoning | Click **Reasoning** icon on a proposal | Agent explains why open items were grouped together |
| 5 | Post proposal | Select a proposal and click **Post** (HITL) | Open items move from "Open" tab to "All" tab with status "Cleared Item" |
| 6 | Delete proposal | Select and delete an unwanted proposal or entire set | Proposal removed from list |
