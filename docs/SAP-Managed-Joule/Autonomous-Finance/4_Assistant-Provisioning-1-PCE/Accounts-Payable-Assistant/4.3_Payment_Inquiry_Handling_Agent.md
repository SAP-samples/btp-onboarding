## Payment Inquiry Handling Agent

### Objective

Handles payment-related inquiries from AP accountants and provides status updates on supplier payments. The agent enables AP teams to quickly retrieve payment information without navigating multiple transactions in the system.

### What It Can Do

- Retrieve payment status for supplier invoices
- Display payment run details and scheduled payment dates
- Provide information on blocked payments and the reasons for the block
- Support queries on open and cleared supplier line items

### Example Prompts

| Prompt |
|--------|
| "What is the payment status of invoice [invoice number] for supplier [supplier ID]?" |
| "Show me open payables for supplier [supplier ID] in company code 1000." |
| "Are there any blocked payments for supplier [supplier ID]?" |
| "When is the next scheduled payment run for company code 1000?" |

> **Note:** Full capabilities and example prompts will be updated here once the Accounts Payable Assistant becomes generally available.
