## Post-Provisioning Validations (PCE)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following group exists:
   - `joule_end_user`

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent-Specific Validations

After provisioning, verify the following for the Recurring Receivables Assistant:

#### Required Roles

Confirm the following business roles are assigned to the user before testing:

| Role | Required For |
|------|-------------|
| `SAP_BR_INTRNAL_SALESREP_SOM` | Subscription Lifecycle Agent |
| `SAP_BR_INVOICING_SPEC_CINV` | Convergent Invoice Execution Agent |
| `SAP_BR_APR_ACCOUNTANT_FICA` | Collection Insights Agent |

#### Functional Checks

- Log in to Joule and confirm the Recurring Receivables Assistant agents are accessible.
- Test the Subscription Lifecycle Agent by requesting details or a change on a known subscription contract.
- Test the Convergent Invoice Execution Agent by requesting invoice document details for a known billing document.
- Test the Collection Insights Agent by requesting collection insights for a FI-CA business partner.
- Confirm the required OData services are active and the business user is authorised to call them (see prerequisites in [2_Prepare](../../2_Prepare/2.4_Prerequisites_Per_Assistant_PCE.md)).
