## Post-Provisioning Validations (PCE)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following groups exist:
   - `joule_end_user`
   - `joule_tenant_admin` (for administrators)

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent-Specific Validations

After provisioning, verify the following for the Accounts Receivable Assistant:

#### Required Roles

Confirm the following business roles are assigned to the user before testing:

| Role | Required For |
|------|-------------|
| `SAP_BR_AR_ACCOUNTANT` | All AR agents (common prerequisite) |

#### Functional Checks

- Log in to Joule and type `@Accounts Receivable Assistant` to confirm the orchestration agent responds.
- Test the Receivable Account Analysis Agent by requesting a receivables overview for a known customer and company code.
- Test the Collection Account Preparation Agent by requesting a collection overview for a customer and collection segment.
- Test the Dunning Insights Agent by requesting dunning analysis for a known customer.
- Test the Dispute Creation Agent by requesting creation of a dispute case for a known billing document.
- Confirm that the Collections Email Outreach Agent is accessible — it requires the policy document to be uploaded before emails can be sent.
- Confirm that the Dispute Resolution Agent is accessible — it requires the policy document to be uploaded before analysing disputes.
