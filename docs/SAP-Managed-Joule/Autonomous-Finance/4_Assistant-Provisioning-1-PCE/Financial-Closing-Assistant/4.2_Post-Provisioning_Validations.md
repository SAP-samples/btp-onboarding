## Post-Provisioning Validations (PCE)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following groups exist:
   - `joule_end_user`
   - `joule_tenant_admin` (for administrators)

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent-Specific Validations

After provisioning, verify the following for the Financial Closing Assistant:

#### Required Roles

Confirm the following business roles and catalogs are assigned to the user before testing:

| Role / Catalog | Required For |
|----------------|-------------|
| Business catalog `SAP_SFIN_BC_GL_JE_PR0C` with restriction type `BUKRS` | Accounting Accruals Agent, Journal Entry Agent |
| Asset Accountant business role | Asset Accounting Anomaly Detection Agent (PCE only) |
| Authorization objects: `F_BKPF_BUK`, `F_SKA1_BUK`, `F_FAGL_LDR`, `F_FDCA_CHK`, `F_CC_HIER` | Financial Consistency Analysis Agent (PCE only) |

#### Functional Checks

- Log in to Joule and type `@Financial Closing Assistant` to confirm the orchestration agent responds.
- Test the Accounting Accruals Agent by requesting an accrual proposal — Joule should prompt you to upload a policy handbook.
- Test the Journal Entry Agent by uploading a spreadsheet file via Joule.
- For the Asset Accounting Anomaly Detection Agent (PCE only): request anomaly detection for a company code and confirm results are returned.
- For the Financial Consistency Analysis Agent (PCE only): request a consistency check for a company code and fiscal year and confirm the agent responds.
