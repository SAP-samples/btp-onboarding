## Test Scripts — Accounts Payable Assistant (Private Cloud)

### Receivables and Payables Clearing Agent — AP Side

> Source: `2026_E2E_APAR_AGENTS_AP.docx`
> Role: `SAP_BR_AP_ACCOUNTANT`; App: **Manage Supplier Clearing Proposals** (F9300)

| # | Scenario | Steps | Expected Result |
|---|----------|-------|----------------|
| 1 | Invoke agent | Open Joule and invoke `@Financial Closing Assistant`; request clearing of supplier open items for a specific supplier and company code | Agent acknowledges and starts processing |
| 2 | Receive notification | Wait for Bell and Email notification | Notification arrives when clearing proposals are created |
| 3 | Review proposals | Navigate to **Manage Supplier Clearing Proposals** (F9300) via Bell notification | Proposal set visible with status "Pending Review" |
| 4 | Review proposal groups | Open proposal set object page | Clearing proposal groups displayed; individual groups can be deleted if not needed |
| 5 | Post proposals | Select one or more groups (multi-select supported) and post | Success message returned; status updates to "Completed" |
| 6 | Delete proposal set | Delete entire proposal set from list page | Proposal set removed |
