## Financial Closing Assistant — Solution Overview

The **Financial Closing Assistant** is a Joule Assistant within SAP Autonomous Finance. It runs on SAP S/4HANA Cloud, Private Edition (RISE with SAP) and automates and accelerates period-end close operations.

It coordinates specialised agents to handle journal entries, accrual recording, open-item clearing, anomaly detection, and financial analysis. The Financial Closing Orchestration Agent manages sequencing and dependencies across all agents, ensuring a transparent and audit-ready close process. All proposed actions require human approval before execution.

### Agents Used by This Assistant

| Agent | Scope |
|-------|-------|
| Financial Closing Orchestration Agent | Coordinates the specialised agents to execute financial closing workflows, managing sequencing and dependencies |
| Journal Entry Agent | Automates data conversion and enforces upfront validation against posting rules |
| Accounting Accruals Agent | Generates pre-populated journal entry proposals for period-end accruals based on historical data and policy documents |
| Analytical Business Insights Agent | Analyses financial KPIs to deliver actionable insights and variance root-cause identification |
| Asset Accounting Anomaly Detection Agent | Detects anomalies in asset accounting transactions before posting |
| Financial Consistency Analysis Agent | Detects discrepancies between ledgers and missing master data, and recommends corrective actions |
| Receivables and Payables Clearing Agent | Generates AI-based matching proposals for open receivables and payables |

### Setup Process at a Glance

1. **Prepare** — Confirm that all prerequisites are in place before activation
