## Complete the Mission

Congratulations on completing the Financial Closing Assistant setup! Use the checklist below to confirm that all required steps have been completed and validated before marking the mission as done.

### Mission Completion Checklist

**Pre-Requisites**

- [ ] SAP S/4HANA Cloud, Private Edition (RISE with SAP) available
- [ ] SAP Managed Joule fully provisioned and active
- [ ] Joule integration with SAP S/4HANA Cloud Private Edition configured
- [ ] SAP Cloud Identity Services active tenant available
- [ ] S-user with Display Cloud Data and Edit Cloud Data permissions in SAP for Me
- [ ] Scope items J58, J59, J60 activated as required
- [ ] Required Fiori apps assigned to relevant users

**Set Up Phase**

- [ ] Financial Closing Assistant activated in SAP for Me under Autonomous Finance
- [ ] Activation confirmed — assistant visible in Joule interface
- [ ] Users added to the `joule_end_user` group in SAP Cloud Identity Services
- [ ] IPS synchronisation run (if applicable)
- [ ] Test user login to Joule confirmed — Financial Closing Assistant available

**Agents Validated**

- [ ] Financial Closing Orchestration Agent tested with at least one example prompt
- [ ] Journal Entry Agent tested with at least one example prompt
- [ ] Accounting Accruals Agent tested with at least one example prompt
- [ ] Analytical Business Insights Agent tested with at least one example prompt
- [ ] Asset Accounting Anomaly Detection Agent tested with at least one example prompt
- [ ] Financial Consistency Analysis Agent tested with at least one example prompt
- [ ] Receivables and Payables Clearing Agent tested with at least one example prompt

### Mark the Mission Complete

Once all required steps are confirmed, mark your DC Mission as complete on the project board.
