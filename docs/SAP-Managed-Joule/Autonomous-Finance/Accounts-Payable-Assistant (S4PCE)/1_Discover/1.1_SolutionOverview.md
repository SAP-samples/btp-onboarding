## Accounts Payable Assistant — Solution Overview

The **Accounts Payable Assistant** is a Joule Assistant within SAP Autonomous Finance. It runs on SAP S/4HANA Cloud, Private Edition (RISE with SAP) and automates accounts payable processes using natural language commands through Joule.

It reduces manual effort across invoice inquiries, ad hoc payments, and open-item clearing. The Accounts Payable Orchestration Agent coordinates the specialised agents and routes user requests to the appropriate agent based on the task. All corrective actions require human approval before execution.

### Agents Used by This Assistant

| Agent | Description |
|-------|-------------|
| Accounts Payable Orchestration Agent | Routes natural language AP requests to the correct specialised agent and coordinates AP workflows |
| Receivables and Payables Clearing Agent | Generates AI-based matching proposals for open payables and receivables |

### Setup Process at a Glance

1. **Prepare** — Confirm that all prerequisites are in place before activation
2. **Set Up** — Provision the Accounts Payable Assistant in SAP for Me and assign users in SAP Cloud Identity Services
3. **Agents** — Explore the two specialised agents, their capabilities, and example prompts
4. **Complete** — Share your feedback and mark the mission as done
