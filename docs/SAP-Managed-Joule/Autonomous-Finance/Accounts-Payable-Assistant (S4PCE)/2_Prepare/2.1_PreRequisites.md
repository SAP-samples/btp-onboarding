## Pre-Requisites

The following components must be in place before the Accounts Payable Assistant can be activated.

- **SAP S/4HANA Cloud, Private Edition (RISE with SAP)** — The Accounts Payable Assistant is supported on SAP S/4HANA Cloud, Private Edition.

- **SAP Managed Joule (SMJ) — fully provisioned** — SMJ must be fully provisioned and active. For SMJ provisioning instructions, refer to the [SAP Managed Joule Provisioning guide](https://help.sap.com/docs/joule/joule-work-621104a90a01407fbb2d1613db39a54d/sap-managed-provisioning).

- **Joule integration with SAP S/4HANA Cloud Private Edition — configured** — The Joule integration must be set up on the S/4HANA side. For setup instructions, refer to the [Joule Integration guide](https://help.sap.com/docs/joule/integrating-joule-with-sap/integration-with-sap-s-4hana-cloud-private-edition).

- **SAP Cloud Identity Services (CIS) — active tenant** — Users must be assigned to the `joule_end_user` group in CIS (see section 3.2).

- **S-user with SAP for Me authorisations** — The activating user must have **Display Cloud Data** and **Edit Cloud Data** permissions in SAP for Me.

- **Scope Item J60** — Scope item J60 (Accounts Payable) must be activated in the system.
