# Accounts Payable Assistant - DC Mission

This directory contains the files for the **Accounts Payable Assistant DC Mission** — a structured guide for activating, configuring, and validating the Accounts Payable Assistant within SAP Autonomous Finance.

## Overview

The Accounts Payable Assistant automates accounts payable processes using natural language commands through Joule. It reduces manual effort across invoice inquiries, ad hoc payments, and open-item clearing. The Accounts Payable Orchestration Agent coordinates the specialised agents and routes user requests to the appropriate agent based on the task. All corrective actions require human approval before execution.

> This guide targets SAP administrators and finance teams activating the Accounts Payable Assistant for their organisation.
