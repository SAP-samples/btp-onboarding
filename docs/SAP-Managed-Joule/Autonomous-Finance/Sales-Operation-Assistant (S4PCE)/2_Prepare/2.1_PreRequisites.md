## Pre-Requisites

The following components must be in place before the Sales Operations Assistant can be activated. Refer to [SAP Note 3792840](https://me.sap.com/notes/3792840) for the definitive list of supported releases and any version-specific requirements.

### Required Prerequisites

- **SAP S/4HANA Cloud, Private Edition (RISE with SAP)** — The assistant is supported exclusively on SAP S/4HANA Cloud, Private Edition under RISE with SAP. On-premise SAP S/4HANA is not supported. Refer to SAP Note 3792840 for the minimum supported release.

- **SAP Managed Joule (SMJ) — fully provisioned** — SMJ must be fully provisioned and active. The Sales Operations Assistant cannot be activated without a working SMJ instance. For SMJ provisioning instructions, refer to the [SAP Managed Joule Provisioning guide](https://help.sap.com/docs/joule/joule-work-621104a90a01407fbb2d1613db39a54d/sap-managed-provisioning).

- **Joule integration with SAP S/4HANA Cloud Private Edition — configured** — The Joule integration must be set up on the S/4HANA side before activation. For setup instructions, refer to the [Joule Integration guide](https://help.sap.com/docs/joule/integrating-joule-with-sap/integration-with-sap-s-4hana-cloud-private-edition).

- **SAP Cloud Identity Services (CIS) — active tenant** — An active CIS tenant is required for user authentication and provisioning. Users must be assigned to the `joule_end_user` group in CIS (see section 3.2).

- **S-user with SAP for Me authorisations** — The activating user must have **Display Cloud Data** and **Edit Cloud Data** permissions in SAP for Me.
