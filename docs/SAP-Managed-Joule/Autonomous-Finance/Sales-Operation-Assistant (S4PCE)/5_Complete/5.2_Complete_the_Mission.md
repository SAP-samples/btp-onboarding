## Complete the Mission

Congratulations on completing the Sales Operations Assistant setup! Use the checklist below to confirm that all required steps have been completed and validated before marking the mission as done.

### Mission Completion Checklist

**Pre-Requisites**

- [ ] SAP S/4HANA Cloud, Private Edition (RISE with SAP) available at the minimum supported release (see SAP Note 3792840)
- [ ] SAP Managed Joule fully provisioned and active
- [ ] Joule integration with SAP S/4HANA Cloud Private Edition configured
- [ ] SAP Cloud Identity Services active tenant available
- [ ] S-user with Display Cloud Data and Edit Cloud Data permissions in SAP for Me

**Set Up Phase**

- [ ] Sales Operations Assistant activated in SAP for Me under Autonomous Finance
- [ ] Activation confirmed — assistant visible in Joule interface on SAP S/4HANA Cloud Private Edition
- [ ] Users added to the `joule_end_user` group in SAP Cloud Identity Services
- [ ] IPS synchronisation run (if applicable)
- [ ] Test user login to Joule confirmed — Sales Operations Assistant available

**Agents Validated**

- [ ] Delivery Issues Resolution Agent tested with at least one example prompt
- [ ] Billing Block Resolution Agent tested with at least one example prompt
- [ ] Supply Issue Resolution Agent tested with at least one example prompt
- [ ] Credit Block Issues Resolution Agent tested with at least one example prompt

### Mark the Mission Complete

Once all required steps are confirmed, mark your DC Mission as complete on the project board.
