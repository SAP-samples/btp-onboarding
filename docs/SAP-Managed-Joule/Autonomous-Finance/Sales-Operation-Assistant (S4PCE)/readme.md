# Sales Operations Assistant - DC Mission

This directory contains the files for the **Sales Operations Assistant DC Mission** — a structured guide for activating, configuring, and validating the Sales Operations Assistant within SAP Autonomous Finance.

## Overview

The Sales Operations Assistant is a Joule Assistant within SAP Autonomous Finance, running on top of SAP S/4HANA Cloud, Private Edition (RISE with SAP). It automates the identification and resolution of sales order fulfilment issues — including delivery blocks, billing blocks, credit blocks, and supply problems — and supports the creation of sales orders from unstructured purchase order documents. All corrective actions require human approval before execution.

> This guide targets SAP administrators and IT teams activating the Sales Operations Assistant for their organisation.
