## Sales Operations Assistant — Solution Overview

The **Sales Operations Assistant** is a Joule Assistant within SAP Autonomous Finance. It runs on top of SAP S/4HANA Cloud, Private Edition (RISE with SAP).

Its objective is to automate the identification and resolution of sales order fulfilment issues, credit blocks, delivery blocks, billing blocks, and supply problems, and to support the creation of sales orders from unstructured purchase order documents. All corrective actions require human approval before execution.

The assistant enables sales teams to quickly identify fulfilment issues, receive recommended resolutions, and create or update sales documents directly in their workflow — minimising manual rework and delays, reducing order-to-cash cycle time, and improving customer satisfaction.

### Tasks This Assistant Can Help With

- Order monitoring and issue resolution
- Monitoring supply, credit, billing, and delivery issues
- Recommending actions to resolve issues
- Categorising agent actions and recommended actions
- Removing blocks
- Executing actions such as removing blocks and creating and updating sales documents after human approval

### Example Use Cases

- Monitoring and resolution of credit, delivery, and supply issues in sales orders
- Recommendations for proposed actions and removal of blocks to ensure sales order fulfilment
- Minimised delivery and payment delays through faster error resolution
- Improved accuracy in sales order data
- Automated sales document creation and update

### Benefits

- **Accelerated problem resolution** — Identify fulfilment issues and speed resolution with actionable solutions
- **Time savings and error reduction** — Automate sales document creation to shorten order cycle times and minimise mistakes
- **Improved deal quality and pricing decisions** — Maintain accurate, up-to-date sales data that supports more informed pricing choices

### Agents Used by This Assistant

The assistant orchestrates four specialised agents. Each agent handles a specific type of fulfilment issue:

| Agent | Description |
|-------|-------------|
| Delivery Issue Resolution Agent | Proposes outbound and partial deliveries, alternative products, or adjusts delivery dates to resolve delivery blocks |
| Billing Block Resolution Agent | Displays billing block details and recommends corrective actions, such as updating payment terms |
| Supply Issue Resolution Agent | Evaluates supply issues across purchasing and manufacturing, verifies production dates, and links related documents |
| Credit Block Issues Resolution Agent | Recommends corrective actions — such as reviewing credit limits or checking open deliveries — to resolve credit block issues |
