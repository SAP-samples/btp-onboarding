## Post-Provisioning Validations (PCE)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following group exists:
   - `joule_end_user`

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent Access Assignment

After SAP-managed provisioning jobs complete, authorization groups for each agent are available in SAP Cloud Identity Services. You must assign users to these groups to grant them access to the agents.

**Prerequisites:**
- SAP-managed provisioning jobs have completed successfully and agent authorization groups are available in SAP Cloud Identity Services
- The users you want to assign already exist in SAP Cloud Identity Services
- You are assigned an administrator role with the **Manage Users** or **Manage Groups** authorizations in the SAP Cloud Identity Services administration console

> Each agent has its own authorization group. Users must be members of an agent's group to see and interact with that agent. Assigning a user to an assistant does not automatically grant access to the agents it invokes — you must assign the user to each one separately.

**Steps:**

1. Sign in to the administration console for SAP Cloud Identity Services.
2. Under **Users & Authorizations**, choose the **Groups** tile.
3. Search for the agent authorization group required.
4. Choose **+ Add**.
5. Add users to the group.
6. Save your changes.

#### Configuration Prerequisites

- In the configuration activity **Define Basic Settings**, **Full Scope** is set for the **Cash Scope** setting — required for both agents.
- Treasury Policy, Short Term Cash Positioning app, Cash Position Profile, and Bank Transfer Templates are configured — required for Cash Positioning Agent.
- The bank hierarchy is set up in the **Manage Bank Accounts - Bank Hierarchy View** app (`F1366`) — required for Bank Relationship Agent.

#### Functional Checks

- Log in to Joule and confirm the Cash and Treasury Assistant agents are accessible.
- Test the Cash Positioning Agent by requesting the current cash position for a known bank account or company code.
- Test the Cash Positioning Agent's bank transfer capability by proposing a transfer to resolve a cash shortfall — confirm the transfer template is available.
- Test the Bank Relationship Agent by requesting bank account information and relationship analysis for a known bank.
