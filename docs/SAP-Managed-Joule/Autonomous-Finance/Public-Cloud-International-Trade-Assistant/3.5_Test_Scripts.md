## 4.3.2 — Classify Products Commodity Codes using the International Trade Classification Agent

**App:** Classify Products - Commodity Codes (F2151)
**Role:** Trade Classification Specialist

> The International Trade Classification Agent classifies products by commodity code. The agent generates a product profile and then produces classification proposals with detailed reasoning.

| # | Step | Instruction | Expected Result | Pass / Fail / Comment |
|---|------|-------------|----------------|-----------------------|
| 1 | Log on | Log on to the SAP Fiori launchpad as a Trade Classification Specialist | SAP Fiori launchpad is displayed | |
| 2 | Open app | Open Classify Products - Commodity Codes (F2151) | The Classify Products Commodity Codes screen is displayed | |
| 3 | Enter filters | Enter: Valid On: 2026-03-01 (must be within the valid period of the commodity code) / Numbering Scheme: EU01 / Product: ZSK_AI_01_FLASK → Choose Go | Product entry displays | |
| 4 | Start classification | Select the checkbox of product ZSK_AI_01_FLASK → Choose **Classify** → Press **Generate Proposals** | The Propose Commodity Code for Trade Classification screen is displayed | |
| 5 | Step 1 — Product information | On the Propose Commodity Code for Trade Classification screen, Step 1 Product information is displayed. Optionally enter additional information in the Additional Information text field, for example: material construction details, features, dimensions. PDF product data sheets can be uploaded to the Attachments field. Press **Step 2** to proceed. | The message "International Trade Classification Agent is generating the product profile" is displayed. Step 2: Product Profile is displayed. | |
| 6 | Step 2 — Product profile | Review the product attributes in Step 2. The product profile is generated by the agent and presents the AI assistant's understanding of the product in terms of its characteristics and intended use. The product profile also includes a pre-analysis of the product according to the General Rules for the interpretation of the Harmonized System (World Customs Organization). Press **Step 3** to proceed. | Message "International Trade Classification Agent is generating proposals" is displayed. Step 3: Generated Proposal is displayed. | |
| 7 | Step 3 — Select and submit proposal | Based on the product profile, the agent generates classification proposals. Open the summary, detailed reasoning, and note analysis sections for each proposed commodity code. Select the proposal that best suits your requirements by pressing **Select Proposal** → confirm by pressing **Submit** → click **Save**. | The proposed commodity code is entered in the field. The classification proposal is generated and the classification of commodity code is saved. | |

> **Note:** The commodity code must be maintained in the Manage Commodity Codes app (F2516) before classifying the product.

## 4.8.2 — Classify Products Customs Tariff Numbers using the International Trade Classification Agent

**App:** Classify Products - Customs Tariff Numbers (F3146)
**Role:** Trade Classification Specialist

> The International Trade Classification Agent classifies products by customs tariff number using the same profile-and-proposal workflow as commodity codes.

| # | Step | Instruction | Expected Result | Pass / Fail / Comment |
|---|------|-------------|----------------|-----------------------|
| 1 | Log on | Log on to the SAP Fiori launchpad as a Trade Classification Specialist | SAP Fiori launchpad is displayed | |
| 2 | Open app | Open Classify Products - Customs Tariff Numbers (F3146) | The Classify Product Customs Tariff Numbers screen is displayed | |
| 3 | Enter filters | Enter: Valid On: 2026-03-01 / Numbering Scheme: DE04 / Product (optional): ZSK_AI_01_FLASK → Choose Go | Product entries are displayed. If a product has already been assigned a customs tariff number, it will not appear in this tile — use Reclassify Products - Customs Tariff Numbers (F3147) instead. | |
| 4 | Start classification | Select the checkbox of product ZSK_AI_01_FLASK → Choose **Classify** → Press **Generate Proposals** | The Propose Customs Tariff Numbers for Trade Classification screen is displayed | |
| 5 | Step 1 — Product information | Step 1 Product information is displayed. Optionally enter additional information in the Additional Information text field. PDF product data sheets can be uploaded to the Attachments field. Press **Step 2** to proceed. | The message "International Trade Classification Agent is generating the product profile" is displayed. Step 2: Product Profile is displayed. | |
| 6 | Step 2 — Product profile | Review the product attributes. The product profile is generated by the agent and presents its understanding of the product, including a pre-analysis according to the General Rules for the interpretation of the Harmonized System. Press **Step 3** to proceed. | Message "International Trade Classification Agent is generating proposals" is displayed. Step 3: Generated Proposal is displayed. | |
| 7 | Step 3 — Select and submit proposal | Review classification proposals. Open the summary, detailed reasoning, and note analysis sections for each proposed customs tariff number. Press **Select Proposal** → confirm by pressing **Submit** → click **Save**. | The proposed customs tariff number is entered in the field. The classification proposal is generated and the classification of customs tariff number is saved. | |

> **Note:** The customs tariff number must be maintained in the Manage Customs Tariff Numbers app (F3122) before classifying the product.
