# International Trade Assistant — Public Cloud Provisioning

This directory contains the provisioning documentation for the **International Trade Assistant** on **SAP S/4HANA Cloud Public Edition**.

## About this Assistant

The International Trade Assistant helps trade compliance specialists automate goods classification for shipping and build comprehensive trade-ready product profiles. It uses specialised agents that apply AI to reduce manual classification effort and ensure trade compliance.

## Agents in this Assistant

| Agent | Purpose |
|-------|---------|
| International Trade Classification Agent | Automatically classifies goods for shipping to save time and ensure compliance |
| International Trade Product Profile Agent | Unifies product data and semantic insights to deliver complete trade-ready product profiles |

## How to Navigate

1. Complete the system-level prerequisites in [2_Prepare](../../2_Prepare/).
2. Follow [3.1](./3.1_Provisioning_in_SAP4Me.md) to activate the assistant in SAP for Me.
3. Run [3.2](./3.2_Post-Provisioning_Validations.md) to verify BTP and CIS configuration.
4. Review the individual agent files to understand what each agent can do and test with the provided example prompts.
5. Run validation scenarios from [3.5 — Test Scripts](./3.5_Test_Scripts.md).
