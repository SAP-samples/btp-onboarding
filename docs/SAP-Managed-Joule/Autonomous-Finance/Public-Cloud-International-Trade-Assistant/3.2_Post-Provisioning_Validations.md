## Post-Provisioning Validations (Public Cloud)

After provisioning, validate that the CIS application and groups are correctly configured, and verify agent connectivity.

### CIS Application and Groups

In your SAP Cloud Identity Services (CIS) admin console:

1. Navigate to **Applications** and confirm the Joule application is listed.
2. Navigate to **Users & Authorizations → Groups** and confirm the following group exists:
   - `joule_end_user`

> If the groups are missing, they are created automatically during provisioning. Allow a few minutes and refresh.

### Agent Access Assignment

After SAP-managed provisioning jobs complete, authorization groups for each agent are available in SAP Cloud Identity Services. You must assign users to these groups to grant them access to the agents.

**Prerequisites:**
- SAP-managed provisioning jobs have completed successfully and agent authorization groups are available in SAP Cloud Identity Services
- The users you want to assign already exist in SAP Cloud Identity Services
- You are assigned an administrator role with the **Manage Users** or **Manage Groups** authorizations in the SAP Cloud Identity Services administration console

> Each agent has its own authorization group. Users must be members of an agent's group to see and interact with that agent. Assigning a user to an assistant does not automatically grant access to the agents it invokes — you must assign the user to each one separately.

**Steps:**

1. Sign in to the administration console for SAP Cloud Identity Services.
2. Under **Users & Authorizations**, choose the **Groups** tile.
3. Search for the agent authorization group required.
4. Choose **+ Add**.
5. Add users to the group.
6. Save your changes.

### Agent-Specific Validations

After provisioning, verify the following for the International Trade Assistant:

#### About These Agents

The International Trade Classification Agent and International Trade Product Profile Agent are embedded AI capabilities invoked directly through the SAP Fiori apps **Classify Products – Commodity Codes** and **Classify Products – Customs Tariff Numbers** in SAP S/4HANA Cloud Public Edition. Step 2 in those apps calls the Product Profile Agent; Step 3 calls the Classification Agent.

Users do not interact with these agents via Joule directly — the agents run inside the Fiori apps. You can query Joule for classification results after the proposals have been generated, for example: *"What is the commodity code for [product description]?"*

#### Required IAM Apps

| IAM App | Description |
|---------|-------------|
| `F2151_TRAN` | Classify Products – Commodity Codes |
| `F3146_TRAN` | Classify Products – Customs Tariff Numbers |
| `F3789_TRAN` | Display Classified Products |

#### Scope Item

| Scope Item | Description |
|------------|-------------|
| **2U3** | Classification for Customs Tariff Number and Commodity Code |

#### Feature Flag

| Feature Flag | Required For |
|--------------|-------------|
| `ITR_TRD_CLS_AI_ASST_BTN_CTRL` | Activates the AI-assisted classification button in the Classify Products apps |

> For support related to this feature flag, use component **FT-ITR-CLS**.

#### Required Configuration

Maintain the language for AI-Assisted Trade Classification in the following configuration activities:

| Configuration Activity | Activity ID |
|-----------------------|-------------|
| Define Numbering Scheme for Customs Tariff Numbers | 103669 |
| Define Numbering Scheme for Commodity Codes | 103666 |

> The International Trade Assistant does not require fuzzy search configuration.

#### Functional Checks

- In the SAP Fiori app **Classify Products – Commodity Codes**, press **Generate Proposals** and confirm Step 2 displays the message *"International Trade Classification Agent is generating the product profile"*.
- Confirm Step 3 lists the classification proposals.
- Repeat the same steps in **Classify Products – Customs Tariff Numbers**.
