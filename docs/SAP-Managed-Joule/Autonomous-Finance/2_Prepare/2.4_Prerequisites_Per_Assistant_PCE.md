## Prerequisites per Assistant — SAP S/4HANA Cloud Private Edition

This page lists the assistant-specific prerequisites for activating each SAP Autonomous Finance assistant on **SAP S/4HANA Cloud Private Edition**. These are in addition to the system-level prerequisites described in [2.2 — Prerequisites per Solution](./2.2_Prerequisites.md).

> **Note:** Some assistants are currently part of an SAP Early Adopter Care (EAC) program. Features in EAC are not available to users outside of this program. Contact your SAP Account Executive for further information.

### Sales Operations Assistant

**Deployment:** SAP S/4HANA Cloud Private Edition

#### Agents Included

| Agent | Purpose |
|-------|---------|
| Credit Block Resolution Agent | Identifies sales orders blocked due to credit limits and proposes corrective actions |
| Billing Block Resolution Agent | Identifies sales orders blocked for billing and proposes resolution steps |
| Delivery Issue Resolution Agent | Identifies sales orders blocked for delivery and proposes actions to unblock fulfilment |
| Supply Issue Resolution Agent | Identifies, analyses, and recommends solutions for supply-related issues |

#### Common Prerequisites (all agents)

- SAP S/4HANA Cloud Private Edition with Sales activated
- SAP Managed Joule — fully provisioned and integrated with SAP S/4HANA Cloud Private Edition
- Business role assigned: **`SAP_BR_INTERNAL_SALES_REP`**
- The following OData services must be activated:

| API | Semantic Object Action |
|-----|------------------------|
| `API_SALESDOCUMENTS_AI` | `SalesOrderFulfillmentIssue-analyzeALPDetails` |
| `SD_SOF` | — |
| `API_SALES_ORDER_SRV` | — |

#### Billing Block Resolution Agent — Additional Prerequisites

- Business role **`SAP_BR_BILLING_CLERK`** must also be assigned (in addition to `SAP_BR_INTERNAL_SALES_REP`)

### Financial Closing Assistant

**Deployment:** SAP S/4HANA Cloud Public Edition and SAP S/4HANA Cloud Private Edition

#### Agents Included

| Agent | Purpose |
|-------|---------|
| Financial Closing Orchestration Agent | Dispatches requests to the appropriate sub-agents in the context of financial closing |
| Accounting Accruals Agent | Automates preparation of manual accruals and generates accrual proposals from an uploaded policy handbook |
| Analytical Business Insights Agent | Evaluates company-level financial status through KPIs and creates summary analyses |
| Asset Accounting Anomaly Detection Agent | Detects data anomalies and inconsistencies in Fixed Asset Accounting (FI-AA) data before period-end close |
| Financial Consistency Analysis Agent | Identifies and corrects data inconsistencies that can prevent clearing processes |
| Journal Entry Agent | Automates and simplifies the creation of journal entries from uploaded spreadsheet data |
| Receivables and Payables Clearing Agent | Automatically generates clearing proposals for open receivable and payable items |

#### Financial Closing Orchestration Agent

- Joule set up and integrated with SAP S/4HANA Cloud Private Edition
- Financial Closing Orchestration Agent activated in SAP for Me

#### Accounting Accruals Agent

- Scope item **J58** (Accounting and Financial Close) activated
- Business role with business catalog `SAP_SFIN_BC_GL_JE_PR0C` with restriction type `Authorization for Company Codes (BUKRS)`
- An accounting policy handbook (PDF) prepared and ready for upload

#### Journal Entry Agent

- Scope item **J58** (Accounting and Financial Close) activated
- Business catalog: `SAP_SFIN_BC_GL_JE_PR0C` with restriction type `Authorization for Company Codes (BUKRS)`

#### Analytical Business Insights Agent

- Access to the **Financial Statements Review Booklet** app
- Decimal format for Country/Region US set to `1,234,567.89` in transaction `0Y01`

#### Asset Accounting Anomaly Detection Agent

> Available on SAP S/4HANA Cloud Private Edition only.

- Premium AI license acquired
- Asset Accountant business role assigned
- Joule set up and integrated with SAP S/4HANA Cloud Private Edition
- For releases lower than SAP S/4HANA 2025 FPS02, implement:
  - SAP Note **3748158** — Backend artifacts of the Asset Accounting Anomaly Detection Agent
  - SAP Note **3719970** — Main Asset Indicator, Lifecycle Status and Completeness Status not supported in P_FixedAsset

#### Financial Consistency Analysis Agent

> Available on SAP S/4HANA Cloud Private Edition only.

- Joule set up and integrated with SAP S/4HANA Cloud Private Edition
- Required authorisations for company code data (FDCA framework)
- Authorization objects: `F_BKPF_BUK`, `F_SKA1_BUK`, `F_FAGL_LDR`, `F_FDCA_CHK`, `F_CC_HIER`
- SAP Notes implemented: 3724077, 3747914, 3725358, 3760025, 3765259, 3799868

#### Receivables and Payables Clearing Agent

- SAP Note **3767703** implemented
- Apps assigned: **Manage Supplier Clearing Proposals** (F9300) and **Manage Customer Clearing Proposals** (F9287)

### Accounts Receivable Assistant

**Deployment:** SAP S/4HANA Cloud Private Edition (minimum: SAP S/4HANA 2023 FPS02)

#### Agents Included

| Agent | Purpose |
|-------|---------|
| Accounts Receivable Orchestration Agent | Routes requests to the appropriate AR sub-agents |
| Receivable Account Analysis Agent | Provides an in-depth overview of a customer's receivable health across invoices, disputes, and credit memos |
| Collection Account Preparation Agent | Consolidates and analyses collection account data to prepare collection specialists for customer outreach |
| Collections Email Outreach Agent | Generates and sends personalised collections emails in the customer's preferred language |
| Dunning Insights Agent | Analyses dunning history and levels, identifies risk, and provides actionable recommendations |
| Dispute Creation Agent | Creates dispute cases from billing documents and unstructured inputs such as user prompts and emails |
| Dispute Resolution Agent | Retrieves comprehensive dispute data, validates claims, and provides tailored resolution recommendations |

#### Accounts Receivable Orchestration Agent

- Joule set up and integrated with SAP S/4HANA Cloud Private Edition 2023 FPS02 or higher
- SAP Dispute Management (FIN-FSCM-DM), SAP Collections Management (FIN-FSCM-COL), and Accounts Receivable Accounting (FI-AR) activated
- Business role assigned: **`SAP_BR_AR_ACCOUNTANT`**

#### Common Prerequisites (all sub-agents)

- SAP S/4HANA Cloud Private Edition 2023 FPS02 or higher
- Business role **`SAP_BR_AR_ACCOUNTANT`** assigned

#### Receivable Account Analysis Agent — Additional Prerequisites

- Joule set up and integrated with SAP S/4HANA Cloud Private Edition
- SAP BTP administration roles for your subaccount
- Following apps assigned:

| App | App ID |
|-----|--------|
| Days Sales Outstanding | F1741 |
| Days Beyond Terms | F1739 |
| Balance Sheet Review | F0703A |
| Display Dunning History | F2328 |
| Manage Customer Line Items | F0711 |
| Manage Dispute Cases | F0702A |

#### Collection Account Preparation Agent — Additional Prerequisites

#### Collections Email Outreach Agent — Additional Prerequisites

### Recurring Receivables Assistant

**Deployment:** SAP S/4HANA Cloud Private Edition (EAC program)

> This assistant is currently part of an SAP Early Adopter Care (EAC) program. Contact your SAP Account Executive for access.

#### Agents Included

| Agent | Purpose |
|-------|---------|
| Subscription Lifecycle Agent | Manages subscription contract changes such as extensions, cancellations, and PO reference updates |
| Convergent Invoice Execution Agent | Handles convergent invoicing document management and billing execution |
| Collection Insights Agent | Provides collection insights and dunning analysis for contract accounting (FI-CA) customers |

#### Common Prerequisites (all agents)

- SAP Managed Joule — fully provisioned and integrated with SAP S/4HANA Cloud Private Edition
- SAP S/4HANA Cloud Private Edition release **2025 FPS01** or higher

#### Subscription Lifecycle Agent — Additional Prerequisites

- Business role: **`SAP_BR_INTRNAL_SALESREP_SOM`** (Internal Sales Representative - SOM)
- For PO reference changes in 2025 FPS01: implement SAP Note **3748784**
- MCPs/APIs consumed:

| MCP | API |
|-----|-----|
| 25_1_API_SUBSCRIPTIONCONTRACT | API_SUBSCRIPTIONCONTRACT |
| 25_1_UI_SUBSCRPNMASSPROCG_MANAGE | UI_SUBSCRPNMASSPROCG_MANAGE |

| 25_1_SUBSCRPN_CANCELLATIONRSNVH | — |
| 25_1_SUBSCRPN_EXTDURATIONVH | — |

#### Convergent Invoice Execution Agent — Additional Prerequisites

- Business role: **`SAP_BR_INVOICING_SPEC_CINV`** (Invoicing Specialist - Convergent Invoicing)
