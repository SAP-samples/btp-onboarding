## Prerequisites per Assistant

This page lists the assistant-specific prerequisites that must be in place before activating each SAP Autonomous Finance assistant. These are in addition to the system-level prerequisites described in the [Prerequisites](./2.2_Prerequisites.md) page.

> **Note:** Some assistants are currently part of an SAP Early Adopter Care (EAC) program. Features in EAC are not available to users outside of this program. Contact your SAP Account Executive for further information.

---

### Sales Operations Assistant

**Deployment:** SAP S/4HANA Cloud Private Edition

The Sales Operations Assistant includes three agents, all with shared prerequisites.

#### Common Prerequisites (all agents)

- SAP S/4HANA Cloud Private Edition with Sales activated
- SAP Managed Joule — fully provisioned and integrated with SAP S/4HANA Cloud Private Edition
- Business role assigned: **`SAP_BR_INTERNAL_SALES_REP`**
- The following OData services must be activated in your SAP S/4HANA Cloud Private Edition system:

| API | Semantic Object Action |
|-----|------------------------|
| `API_SALESDOCUMENTS_AI` | `SalesOrderFulfillmentIssue-analyzeALPDetails` |
| `SD_SOF` | — |
| `API_SALES_ORDER_SRV` | — |

#### Billing Block Resolution Agent — Additional Prerequisites

- Business role **`SAP_BR_BILLING_CLERK`** must also be assigned (in addition to `SAP_BR_INTERNAL_SALES_REP`)

### Financial Closing Assistant

**Deployment:** SAP S/4HANA Cloud Public Edition and SAP S/4HANA Cloud Private Edition

The Financial Closing Assistant uses an orchestration agent that dispatches requests to several specialised agents. Prerequisites apply at two levels: the orchestration agent and each individual sub-agent.

#### Financial Closing Orchestration Agent

- Joule set up and integrated with SAP S/4HANA Cloud Public Edition or SAP S/4HANA Cloud Private Edition
- Financial Closing Orchestration Agent activated in SAP for Me

> Use of this feature may require additional entitlements. Please consult your SAP Account Executive for more information.

#### Accounting Accruals Agent

- Scope item **J58** (Accounting and Financial Close) activated
- Business role with business catalog:
  - SAP S/4HANA Cloud Public Edition: `SAP_FIN_BC_GL_JE_PROC_PC` with restriction type `Authorization for Company Codes (BUKRS)`
  - SAP S/4HANA Cloud Private Edition: `SAP_SFIN_BC_GL_JE_PR0C` with restriction type `Authorization for Company Codes (BUKRS)`
- An accounting policy handbook (PDF) prepared and ready for upload

#### Journal Entry Agent

- Scope item **J58** (Accounting and Financial Close) activated
- SAP S/4HANA Cloud Public Edition — IAM app: **Manage Journal Entry Proposals** (F9263_TRAN)
- SAP S/4HANA Cloud Private Edition — business catalog: `SAP_SFIN_BC_GL_JE_PR0C` with restriction type `Authorization for Company Codes (BUKRS)`

#### Analytical Business Insights Agent

- Access to the **Financial Statements Review Booklet** app
- For SAP S/4HANA Cloud Private Edition: decimal format for Country/Region US set to `1,234,567.89` in transaction `0Y01`

#### Asset Accounting Anomaly Detection Agent

> Available on SAP S/4HANA Cloud Private Edition only.

- Premium AI license acquired
- Asset Accountant business role assigned in SAP S/4HANA Cloud Private Edition
- Joule set up and integrated with SAP S/4HANA Cloud Private Edition
- For releases lower than SAP S/4HANA 2025 FPS02, implement the following SAP Notes:
  - SAP Note 3748158 — Backend artifacts of the Asset Accounting Anomaly Detection Agent
  - SAP Note 3719970 — Main Asset Indicator, Lifecycle Status and Completeness Status not supported in P_FixedAsset

#### Financial Consistency Analysis Agent

> Available on SAP S/4HANA Cloud Private Edition only.

- Joule set up and integrated with SAP S/4HANA Cloud Private Edition
- Required authorisations for company code data (FDCA framework)
- Authorization objects: `F_BKPF_BUK`, `F_SKA1_BUK`, `F_FAGL_LDR`, `F_FDCA_CHK`, `F_CC_HIER`
- SAP Notes implemented: 3724077, 3747914, 3725358, 3760025, 3765259, 3799868

### Accounts Receivable Assistant

**Deployment:** SAP S/4HANA Cloud Private Edition

Requires SAP S/4HANA Cloud Private Edition 2025 FPS01 or higher.

#### Accounts Receivable Orchestration Agent

- Joule set up and integrated with SAP S/4HANA Cloud Private Edition 2025 FPS01 or higher
- SAP S/4HANA Cloud Private Edition components activated:
  - SAP Dispute Management (FIN-FSCM-DM)
  - SAP Collections Management (FIN-FSCM-COL)
  - Accounts Receivable Accounting (FI-AR)
- Business role assigned: **`SAP_BR_AR_ACCOUNTANT`**

> Use of this feature may require additional entitlements. Please consult your SAP Account Executive for more information.

#### Collection Account Preparation Agent

- SAP S/4HANA Cloud Private Edition 2025 FPS01 or higher
- SAP BTP administration roles for your subaccount
- Business role `SAP_BR_AR_ACCOUNTANT` assigned
- Following apps assigned to your user:

| App Name | App ID |
|----------|--------|
| UDMO_COLLECTION_WORKLIST | F0380 |
| UI_PROCESSRECEIVABLES_MAN | F0106A |
| UI_RESUBMISSIONS_MANAGE | F4709 |
| UI_CUSTOMER_CONTACT_MANAGE | F4707 |

#### Collections Email Outreach Agent

- SAP S/4HANA Cloud Private Edition 2025 FPS01 or higher
- Business role `SAP_BR_AR_ACCOUNTANT` assigned
- Scope item **BFC** (Collection & Dispute Management) activated
- Default customer contact with email address maintained in the **Process Receivables** (F0106) app
- Following apps assigned:

| App | App ID |
|-----|--------|
| Process Receivables | F0106 |
| Manage Customer Contact | F4707 |
| Manage Collection Emails | F6120 |
| Manage Business Partner | F3163 |

- Policy document uploaded containing Contact Type and Result of Activity specifications

#### Dispute Creation Agent

- SAP S/4HANA Cloud Private Edition 2025 FPS01 or higher
- Business role `SAP_BR_AR_ACCOUNTANT` assigned
  - Note: Additional authorization required for related objects such as Billing Documents
- Scope item **BFC** (Collection and Dispute Management) activated

|-----|--------|
| Manage Dispute Cases | F0702A |
| Display Process Flow | F2692 |
| Process Receivables | F0106A |

- SAP BTP administration roles for your subaccount

- Business role `SAP_BR_AR_ACCOUNTANT` assigned
  - Note: Additional authorization required for Billing Documents, Outbound Deliveries, Payment Terms, and related objects
- Scope item **BFC** (Collection & Dispute Management) activated
- SAP BTP administration roles for your subaccount
- Following apps assigned:

| App | App ID |
|-----|--------|
| Manage Dispute Cases | F0702A |
| Manage Journal Entries | F0717A |
| Manage Business Partner Master Data | F3163 |

| Display Process Flow – Accounts Receivable | F2692 |
| Manage Bank Statements | F1564 |

- Policy document uploaded specifying Case Type, Reason Code, Reason, and Agent Resolution Path

#### Dunning Insights Agent

- SAP S/4HANA Cloud Private Edition 2025 FPS01 or higher
- Joule set up and integrated with SAP-Managed Provisioning 2025 FPS01 or higher
