## Prerequisites per Assistant — SAP S/4HANA Cloud Public Edition

This page lists the assistant-specific prerequisites for activating each SAP Autonomous Finance assistant on **SAP S/4HANA Cloud Public Edition**. These are in addition to the system-level prerequisites described in [2.2 — Prerequisites per Solution](./2.2_Prerequisites.md).

> **Note:** Some assistants are currently part of an SAP Early Adopter Care (EAC) program. Features in EAC are not available to users outside of this program. Contact your SAP Account Executive for further information.

---

### Financial Closing Assistant

**Deployment:** SAP S/4HANA Cloud Public Edition and SAP S/4HANA Cloud Private Edition

#### Agents Included

| Agent | Purpose |
|-------|---------|
| Financial Closing Orchestration Agent | Dispatches requests to the appropriate sub-agents in the context of financial closing |
| Accounting Accruals Agent | Automates preparation of manual accruals and generates accrual proposals from an uploaded policy handbook |
| Analytical Business Insights Agent | Evaluates company-level financial status through KPIs and creates summary analyses |
| Journal Entry Agent | Automates and simplifies the creation of journal entries from uploaded spreadsheet data |
| Receivables and Payables Clearing Agent | Automatically generates clearing proposals for open receivable and payable items |

> **Note:** The Asset Accounting Anomaly Detection Agent and Financial Consistency Analysis Agent are available on SAP S/4HANA Cloud Private Edition only.

#### Financial Closing Orchestration Agent

- Joule set up and integrated with SAP S/4HANA Cloud Public Edition
- Financial Closing Orchestration Agent activated in SAP for Me

#### Accounting Accruals Agent

- Scope item **J58** (Accounting and Financial Close) activated
- Business role with business catalog `SAP_FIN_BC_GL_JE_PROC_PC` with restriction type `Authorization for Company Codes (BUKRS)`
- An accounting policy handbook (PDF) prepared and ready for upload

#### Journal Entry Agent

- Scope item **J58** (Accounting and Financial Close) activated
- IAM app: **Manage Journal Entry Proposals** (F9263_TRAN)

#### Analytical Business Insights Agent

- Access to the **Financial Statements Review Booklet** app

#### Receivables and Payables Clearing Agent

- Scope items **J59** (Accounts Receivable) and **J60** (Accounts Payable) activated
- IAM apps assigned: **Manage Supplier Clearing Proposals** (F9300_TRAN) and **Manage Customer Clearing Proposals** (F9287_TRAN)

### Accounts Receivable Assistant

**Deployment:** SAP S/4HANA Cloud Public Edition and SAP S/4HANA Cloud Private Edition

#### Agents Included

| Agent | Purpose |
|-------|---------|
| Accounts Receivable Orchestration Agent | Routes requests to the appropriate AR sub-agents across collections, disputes, dunning, and clearing |
| Receivable Account Analysis Agent | Provides an in-depth overview of a customer's receivable health across invoices, disputes, and credit memos |
| Collection Account Preparation Agent | Consolidates and analyses collection account data to prepare collection specialists for customer outreach |
| Collections Email Outreach Agent | Generates and sends personalised collections emails in the customer's preferred language |
| Dunning Insights Agent | Analyses dunning history and levels, identifies risk, and provides actionable recommendations |
| Dispute Creation Agent | Creates dispute cases from billing documents and unstructured inputs such as user prompts and emails |
| Dispute Resolution Agent | Retrieves comprehensive dispute data, validates claims, and provides tailored resolution recommendations |

> **Note:** Full agent-level prerequisites for SAP S/4HANA Cloud Public Edition will be updated here once the assistant becomes generally available on Public Edition.

### Accounts Payable Assistant

**Deployment:** SAP S/4HANA Cloud Public Edition and SAP S/4HANA Cloud Private Edition

#### Agents Included

| Agent | Purpose |
|-------|---------|
| Accounts Payable Orchestration Agent | Routes requests to the appropriate AP sub-agents |
| Receivables and Payables Clearing Agent | Generates clearing proposals for open receivable and payable items |

#### Common Prerequisites (all agents)

- SAP Managed Joule — fully provisioned and integrated with SAP S/4HANA Cloud Public Edition
- Scope item **J60** (Accounts Payable) activated
- Business role with AP accountant authorisations assigned

#### Receivables and Payables Clearing Agent — Additional Prerequisites

- Scope items **J59** (Accounts Receivable) and **J60** (Accounts Payable) activated
- IAM apps assigned: **Manage Supplier Clearing Proposals** (F9300_TRAN) and **Manage Customer Clearing Proposals** (F9287_TRAN)

> **Note:** Full prerequisites for the Accounts Payable Assistant will be updated here once the assistant becomes generally available.

### Cash and Treasury Assistant

**Deployment:** SAP S/4HANA Cloud Public Edition and SAP S/4HANA Cloud Private Edition

#### Agents Included

| Agent | Purpose |
|-------|---------|
| Cash and Treasury Orchestration Agent | Routes requests to the appropriate treasury sub-agents |
| Cash Positioning Agent | Provides visibility into cash positions across bank accounts and supports daily liquidity management |
| Bank Relationship Agent | Manages bank account master data and supports bank relationship activities |

#### Common Prerequisites (all agents)

- SAP Managed Joule — fully provisioned and integrated with SAP S/4HANA Cloud Public Edition
- Treasury and Risk Management (TRM) or Cash Management module activated
- Business role with treasury authorisations assigned

> **Note:** Full prerequisites for the Cash and Treasury Assistant will be updated here once the assistant becomes generally available on Public Edition.
