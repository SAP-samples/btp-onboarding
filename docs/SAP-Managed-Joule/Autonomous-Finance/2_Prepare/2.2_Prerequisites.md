## Prerequisites per Solution

Before activating any SAP Autonomous Finance assistant, the following system-level prerequisites must be in place. Requirements differ by deployment model.

---

### SAP S/4HANA Cloud Public Edition

- **SAP S/4HANA Cloud Public Edition** — Autonomous Finance assistants are supported on SAP S/4HANA Cloud Public Edition. Ensure the system is on a supported release.

- **SAP Managed Joule (SMJ) — fully provisioned** — SMJ must be fully provisioned and active before any assistant can be activated. For SMJ provisioning instructions, refer to the [SAP Managed Joule Provisioning guide](https://help.sap.com/docs/joule/joule-work-621104a90a01407fbb2d1613db39a54d/sap-managed-provisioning).

- **Joule integration with SAP S/4HANA Cloud Public Edition — configured** — The Joule integration must be set up on the S/4HANA side.

- **SAP Cloud Identity Services (CIS) — active tenant** — An active CIS tenant is required for user authentication and provisioning.

- **S-user with SAP for Me authorisations** — The activating user must have **Display Cloud Data** and **Edit Cloud Data** permissions in SAP for Me.

---

### SAP S/4HANA Cloud Private Edition

- **SAP S/4HANA Cloud Private Edition** — Autonomous Finance assistants are supported on SAP S/4HANA Cloud Private Edition under RISE with SAP. On-premise SAP S/4HANA is not supported.

- **SAP Managed Joule (SMJ) — fully provisioned** — SMJ must be fully provisioned and active before any assistant can be activated. For SMJ provisioning instructions, refer to the [SAP Managed Joule Provisioning guide](https://help.sap.com/docs/joule/joule-work-621104a90a01407fbb2d1613db39a54d/sap-managed-provisioning).

- **Joule integration with SAP S/4HANA Cloud Private Edition — configured** — The Joule integration must be set up on the S/4HANA side. For setup instructions, refer to the [Joule Integration guide](https://help.sap.com/docs/joule/integrating-joule-with-sap/integration-with-sap-s-4hana-cloud-private-edition).

- **SAP Cloud Identity Services (CIS) — active tenant** — An active CIS tenant is required for user authentication and provisioning.

- **S-user with SAP for Me authorisations** — The activating user must have **Display Cloud Data** and **Edit Cloud Data** permissions in SAP for Me.
