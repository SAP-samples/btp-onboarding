## Prepare for Joule Work Desktop Provisioning

Before starting the setup of Joule Work Desktop, confirm the following requirements and familiarize yourself with the user roles that will be created during provisioning.

### Required Prerequisites

To proceed with JWD provisioning, you will need:

- **SAP AI Units** (product number `8019164`) — must be entitled in your SAP contract
- **SAP Cloud Identity Services** — a productive tenant is required (not a test or trial tenant)
- **S-User ID with Admin Privileges** — administrator access to [me.sap.com](https://me.sap.com)

If you are currently in the ordering process or have not yet purchased SAP AI Units, we recommend reaching out to your SAP Account Executive or sales representative for support with the commercial contracts.

### Optional Prerequisites

If you plan to enable Microsoft Entra SSO or Microsoft 365 email and calendar integration, you will also need a **Microsoft Entra Administrator** to complete those steps.

### Account Hierarchy Recommendation

JWD provisioning requires a **resource group** as the target container. We recommend the following structure:

```
Organization (Global Account)
└── Resource Group (e.g., "JWD Resource Group")
    └── JWD Tenant (provisioned automatically)
```

> **Tip:** If your account hierarchy is not yet configured, do this in the **Resources** tab of SAP for Me before starting provisioning.

### Supported Regions

JWD is currently available in the following regions:

| Region | SAP BTP Data Center |
|--------|---------------------|
| Germany / European Union | **EU10** (recommended) |
| USA / USA East | **US10** |

> **Note:** Germany (EU10) is the preferred and recommended region.

### User Roles Created During Provisioning

When provisioning completes, two authorization groups are automatically created in your SAP Cloud Identity Services tenant:

- **`gateway - AdminJouleDesktop`** — Administrator role that grants access to the JWD Admin Portal to configure tenant settings
- **`gateway - UseJouleDesktop`** — Standard user role required for all end users to log in to JWD

Users assigned to the `AdminJouleDesktop` group can access the JWD Admin Web UI to enable or disable automatic updates, set AI usage guidelines, enable Spaces, configure custom guardrails, manage user quotas, configure Microsoft 365 integration, and more.

Users assigned to the `UseJouleDesktop` group can log in to the JWD desktop client and use AI conversations, Spaces, and Skills. They can also connect their Microsoft 365 email and calendar if the administrator has enabled this feature.

> **Important:** Without assignment to `UseJouleDesktop`, users will receive an **Access Denied** error when trying to log in to the JWD client.
