## Set Up Microsoft Outlook Integration

> **Optional** — Complete this step if you want to enable Microsoft 365 email and calendar access in JWD, or configure Microsoft Entra SSO for your users.

SAP Joule Work Desktop supports third-party Identity Provider authentication and Microsoft 365 connectivity. This guide covers three areas: configuring Microsoft Entra SSO in IAS, registering an Azure app and granting Microsoft Graph API permissions for email and calendar access, and validating that the integration works correctly.

### Part 1 — Configure Microsoft Entra SSO in IAS

Log in to **SAP Cloud Identity Services** and navigate to **Applications & Resources → Applications**. Search for and open your JWD application, then click **Authentication and Access → Conditional Authentication**.

Click **Add Rule** and configure the authentication rule. Set the **Identity Provider** to your Microsoft Entra IdP, enter your company's email domain (for example, `contoso.com`), and set Priority to `1`. This routes users with matching email domains to authenticate via Microsoft Entra.

</p>

### Part 2 — Configure Identity Federation

When using a corporate IdP such as Microsoft Entra, you must configure **Identity Federation** so that IAS group assignments are passed through correctly. Without this configuration, users will receive **Access Denied** errors even when assigned to the correct IAS group.

In your JWD IAS application, scroll to **Identity Federation** and click **Edit**. Change the **Source** from `Corporate IdP` to **`Custom`**.

<p align="center">
  <img src="./images/3.5.2.png" width="80%">
</p>

Check the **Use Identity Authentication user store** checkbox. This ensures that user attributes — including group assignments — are taken from the IAS user store rather than from the corporate IdP assertion.

<p align="center">
  <img src="./images/3.5.3.png" width="80%">
</p>

Click **Attributes** in the IAS application and confirm that the `groups` attribute from **Identity Directory** is passed through. The required attributes are: `email`, `family_name`, `given_name`, `groups` (All Groups), and `user_uuid`.

### Part 3 — Register an App in Microsoft Entra for Email & Calendar

Open the **Microsoft Entra admin center** and navigate to **Entra ID → App registrations**.

<p align="center">
  <img src="./images/3.5.20.png" width="80%">
</p>

Click **New Registration**. Enter a name such as `JWD-App`, select **Single tenant** as the supported account type, and set the **Redirect URI** to Platform: `Public client/native (mobile & desktop)` with URL `http://localhost`. Click **Register**.

<p align="center">
  <img src="./images/3.5.5.png" width="80%">
</p>

From the **Overview** page, record the **Application (client) ID** and **Directory (tenant) ID** — you will need both for the JWD Admin Portal configuration.

<p align="center">
  <img src="./images/3.5.9.png" width="80%">

Click **Authentication** in the left menu and confirm that the redirect URI shows `http://localhost` under **Mobile and desktop applications**.

### Part 4 — Update the JWD Admin Portal

Navigate to the **JWD Admin Portal** and go to the **Microsoft 365 Integration** section. Toggle on **Enable Work Email** and **Enable Work Calendar**. Enter the **Microsoft 365 Application ID** (client ID) and **Microsoft 365 Directory ID** (tenant ID) you recorded earlier. Click **Save** next to each field.

<p align="center">
  <img src="./images/3.5.8.png" width="80%">
</p>

> **Note:** Work Email is auto-enabled in the JWD client after saving. Work Calendar must be toggled on manually by each user in their JWD Settings.

### Part 5 — Validate Email and Calendar

To enable the Work Calendar, each user must do this manually in their JWD settings. In JWD, click the profile icon, click **Settings**, navigate to the **Account** tab, and under **Microsoft Account**, toggle **Calendar** to enabled.

<p align="center">
  <img src="./images/3.5.18.png" width="80%">
</p>

To test email access, start a new conversation in JWD and type:

```
What is my last email?
```

JWD should return a summary of your most recent email including sender, subject, date, and a preview.

<p align="center">
  <img src="./images/3.5.19.png" width="80%">
</p>

To test calendar access, type:

```
What do I have on my calendar today?
```

JWD should return a summary of today's calendar events.

### Troubleshooting

If you receive an **Access Denied** error when logging in to JWD, verify that the user is assigned to the `UseJouleDesktop` IAS group. If email is not accessible, confirm that the `Mail.Read` permission is granted in the Azure App Registration. If the calendar is not showing, ensure that `Calendars.Read` is granted and admin consent has been given. If you see **No Connector** in JWD, confirm that Microsoft 365 integration is enabled in the JWD Admin Portal.
