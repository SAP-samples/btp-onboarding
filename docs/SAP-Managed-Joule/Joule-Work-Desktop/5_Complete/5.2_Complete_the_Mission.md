## Complete the Mission

Congratulations on completing the Joule Work Desktop setup! Use the checklist below to confirm that all required steps have been completed and validated before marking the mission as done.

### Mission Completion Checklist

**Set Up Phase**

- [ ] JWD provisioned with **Ready** status in SAP for Me
- [ ] Gateway URL and Tenant ID noted from Access Information
- [ ] JWD application visible in SAP Cloud Identity Services
- [ ] `gateway - AdminJouleDesktop` and `gateway - UseJouleDesktop` groups created in IAS
- [ ] Admin user assigned to `AdminJouleDesktop` group
- [ ] End users assigned to `UseJouleDesktop` group
- [ ] JWD client downloaded from SAP for Me Software Center
- [ ] JWD client installed and login successful

**Optional Steps (if configured)**

- [ ] JWD Admin Portal accessible
- [ ] Microsoft Entra conditional authentication rule added in IAS
- [ ] Identity Federation configured with IAS user store enabled
- [ ] Azure App Registration created with required Microsoft Graph API permissions
- [ ] Admin consent granted for all API permissions
- [ ] Microsoft 365 Application ID and Directory ID saved in JWD Admin Portal
- [ ] Email integration working (`What is my last email?`)
- [ ] Calendar integration working (`What do I have on my calendar today?`)
- [ ] MCP servers registered in Admin Portal (if developed)

### Mark the Mission Complete

Once all required steps are confirmed, mark your DC Mission as complete on the project board.

### Tenant Lifecycle: Delete JWD

If you need to decommission the JWD tenant, follow the steps below.

> **Caution:** Deletion is **irreversible**. All tenant data, user sessions, and configuration are permanently removed.

Before deleting, ensure that all JWD users have been notified, that users have exported any important data via **Settings → Account → Personal Data → Export**, and that you have confirmed this is the correct JWD tenant to delete. Note that you should delete only the JWD solution entry — not the Resource Group.

Deletion impacts include permanent removal of all tenant configuration and stored data, immediate termination of all active user sessions, loss of all conversations, spaces, and skills saved in the client, and removal of the JWD application and associated user groups from IAS.

To delete the JWD tenant, log in to [https://me.sap.com](https://me.sap.com) and navigate to **Portfolio & Products → My Product Packages → Artificial Intelligence → Joule**. Click the **Resources** tab, locate your **JWD Solution entry** in the resources hierarchy (not the Resource Group), click the **Actions** button (three-dot menu) next to the JWD tenant, and click **Delete**.

A confirmation dialog appears. Check the confirmation box and click **Delete Solution and Tenants**.

After deletion, the JWD entry is removed from the Resources section in SAP for Me, the JWD application is no longer visible in SAP Cloud Identity Services, and the `gateway - AdminJouleDesktop` and `gateway - UseJouleDesktop` groups are removed from Groups.

To set up JWD again after deletion, start the full provisioning process from the beginning of the Set Up phase.
